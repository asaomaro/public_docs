# memo-search

## 目的
メモが増えると目当ての1件を探せなくなる。一覧の上でキーワードを打つと、
その場で絞り込めるようにしたい。

## やること
- 一覧の上に検索欄を置く
- 入力したキーワードで、メモの本文を絞り込む
- 検索欄を空にすると全件に戻る

## やらないこと
- タイトルだけ／本文だけ、の検索対象の切り替え（本文のみ固定）
- あいまい検索・表記ゆれの吸収（完全な部分一致のみ）
- 検索履歴の保存
- 大文字小文字の区別（区別しない、で固定）

## 受け入れ条件
- [ ] 検索欄に「会議」と入れると、本文に「会議」を含むメモだけが一覧に出る
- [ ] 検索欄を空にすると、全件が一覧に戻る
- [ ] 一致が0件のとき、一覧は空になり「該当なし」と表示される
- [ ] 「カイギ」と「かいぎ」は別物として扱う（表記ゆれは吸収しない）
- [ ] 「Meeting」と入れると「meeting」を含むメモも出る（大文字小文字は区別しない）
