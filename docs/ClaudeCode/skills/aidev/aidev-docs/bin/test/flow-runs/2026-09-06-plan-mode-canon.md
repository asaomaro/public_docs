### 判断基準を書き、全 11 工程を導出可能にした

従来は工程ごとの可否だけが列挙され、**requirement と walkthrough がどちらのリストにも無かった**。
除外理由の一部も「実装計画ではない」で論点がずれていた——plan モードで禁じられるのは
Write / Edit だけで、読み取りも `AskUserQuestion` による対話も動く。

実走が基準だけで導出を試み、**9/11 しか導出できなかった**ので 3 点を足した:

- **「aidev のゲート」の範囲**が未定義で、素直に読むと coding が「入る」に化けた
  → 「その工程 および上流のゲートが既に承認したもの」と明示
- **research は基準の外の規則**（純粋な調査は「2.6」の委譲）なのに基準から導けるように並んでいた
  → 「基準の外の規則で外す」と明示
- **walkthrough の除外理由が当てはまっていなかった**（説明文書であって「判断そのもの」ではない）
  → 「方針と成果物が分離できない」に言い換え
