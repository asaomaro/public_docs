### 実走が見つけた must（2 件）

1. **私がこのラウンドで入れた欠陥**。`die` の二重引用符の中に逆引用符を書いており、POSIX sh の
   コマンド置換として **`mkdir -p .aidev/works` が実際に実行され**、cwd に `.aidev/works` を作った
   うえ案内文もその位置から消えた。**未導入 PJ で最初に打つ経路**なので被害が大きい。
   ps1 では逆引用符はエスケープ文字なので**壊れ方が違い、パリティ検査も通した**
   ——`pass=1003 fail=0` のまま素通りしていた。実走 C・D が独立に同じものを報告。
2. **`verify` の「差し戻しがあったのに生出力が無い」WARN が `by: unapprove` を除外していない**。
   統合 review から子へ差し戻すと子に `by: unapprove` の `sent_back` が刻まれるが、**子では一度も
   test が落ちていない**ので貼れる生出力が無い。書いてある解消法（生出力を貼る）に従うと親の
   出力を子へ写すことになり「捏造しない」と衝突する——**消せない WARN** だった。
   `dbg_sent_backs` / `metrics` / `debug status` は最初からこの除外をしており、ここだけ抜けていた。
