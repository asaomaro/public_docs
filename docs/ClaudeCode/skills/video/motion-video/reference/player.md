# プレイヤーの操作と機能

見る人への案内を書くとき・プレイヤーの動きを確かめるときに読む（全テンプレート共通）。

## 操作

| 操作 | ボタン | キー |
|---|---|---|
| 再生・一時停止 | ▶／❚❚、映像のクリック | `Space`・`K` |
| 停止（最初に戻る） | ■ | `S` |
| 5 秒戻る・進む | シークバー | `←`・`→` |
| 前・次のチャプター | ⏮・⏭、チャプターの一覧 | `[`・`]` |
| 速度（0.5〜2 倍） | 選択欄 | `<`・`>` |
| 字幕のオン・オフ | 字幕 | `C` |
| 音声のオン・オフ | スピーカー | `M` |
| 音量 | スピーカーの横のつまみ（動かした間、つまみの上に % が出る） | `↑`・`↓`（10% ずつ） |
| 小窓で再生（ピクチャー・イン・ピクチャー） | 画面の中に小さな画面のアイコン（対応するブラウザだけ） | — |
| 全画面 | ⛶ | `F` |

- 操作部は常に 1 行。長いチャプター名は … で省略し、省略したときはツールチップで全部を出す。映像の側が狭いときは、
  チャプター名 → 音量のつまみ → 停止 → 前・次のチャプター → 小窓 → 速度 → チャプターのメニューの順に隠す（キー操作やほかの場所に代わりがあるものから）。
- シークバーはチャプターごとに区切られ、触れると時刻とチャプター名が出る。キーボードでも操作できる（`Home`・`End`・`PageUp/Down`）。
- 速度・字幕・音声・音量・書体の選択は、見る人のブラウザに保存される。
- 読み上げは、再生・倍速に合わせて字幕の区切りごとに話す。シークしたときは次の字幕から話す。
- **読み上げが字幕の時間に収まらないときは、読み終わるまで動画がその位置で待つ**（声の速さは OS とブラウザで違うため）。
  一時停止・シーク・停止で待ちは解け、声が無い環境では待たない。待たせたくない（映像の時間を優先する）ときは `audio.wait: false`。
- **ブラウザの声の速さに合わせて時間の表示を直す**: 話し終えた字幕から実際の長さを測り、まだ来ていない場面の長さ・字幕の時刻・
  合計の時間・チャプターの時刻を直す（最初の 1〜2 文の後から合う）。測った速さは声ごとにブラウザに覚え、次からは最初から合った時間で始まる。
  そのため、ブラウザの声のときは、同じ台本でも見る環境によって合計の時間とチャプターの時刻が変わる。止めるときは `audio.adapt: false`。
  前もって作った声（`voice.md`）では直さない（もともと正確）。
- 場面の長さの見積もりは、`audio.pronounce` で置き換えた後の読み方の文字数で数える（読みが長くなる語も含めて見積もる）。

## 機能

- **シークバーのプレビュー**: 触れた時刻の画を小さく描く（描画が時刻だけで決まるので、その場で 1 コマ描ける）。
- **文字起こし**: `theater` で横に出る。クリックでその位置へ、検索で絞り込み。
- **続きから再生**: 前回の位置を見る人のブラウザに覚え、次に開いたとき「前回の続き（m:ss）から再生」を出す。
- **設定（⚙）**: 字幕の大きさ（小・標準・大）、表示（プレイヤーの操作部・一覧・メニューの色。テーマのまま・ライト・ダーク・システム＝OS の設定に従う。映像の中はテーマの色のまま）、書体（映像の文字・字幕・プレイヤーの文字（チャプターの一覧・メニュー・設定・文字起こし。時刻などの等幅は除く）。テーマの既定・ゴシック・明朝・丸ゴシック・UD・メイリオ・教科書体のうち、見る人の OS に入っているものだけ出る）、音楽・効果音の入り切り（見る人のブラウザに保存）、**動画ファイル（WebM）で保存**
  （最初から 1 倍速で再生しながら録画。字幕は映像に焼き込み、音楽と効果音は入り、読み上げの声は入らない）、
  **保存の設定**（解像度 1280×720・**1920×1080（既定）**・2560×1440・3840×2160／画質＝映像のビットレート 自動・4〜40 Mbps（自動は 720 で 5、1080 で 8、1440 で 16、2160 で 35 Mbps。60 コマは 1.5 倍）／
  コマ数 30・60／音質 128〜320 kbps／形式 WebM（VP9・VP8・AV1）・MP4（H.264）。ブラウザが録れる形式だけ出る。選んだものは見る人のブラウザが覚える。ショートは縦横が入れ替わる）、
  **編集用の映像**（字幕・音なし の WebM。解像度とコマ数は保存の設定に従い、画質は 12 Mbps 以上）、**音のトラックを書き出す**（声・音楽・効果音・全部を別々の WAV に。video-export スキルと組で使う）。
- **キー**: `J`・`L` で 10 秒、`0`〜`9` で 0〜90% の位置へ（上の表の操作に加えて）。
- **1 ページに複数のプレイヤー**: 1 つを再生すると、ほかは止まる。
