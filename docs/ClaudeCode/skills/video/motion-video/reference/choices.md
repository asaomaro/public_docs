足した 11 種は、本文の字（ink）と地（bg0・bg1・panel）が 10:1 以上、補助の字（muted）が 4.5:1 以上、グラフの 4 色が地と 3:1 以上で、4 色どうしも見分けられる色差にしてある。
景色の背景（`bg`）と組むときは、明るさの合う配色を選ぶ（`backgrounds.md`）。

質問（header の例）:

1. **プレイヤー**（「プレイヤー」）: 内容に合う 3 件（1 件目に「（おすすめ）」）＋`studio`。`studio` が 3 件に入っていれば次点。
2. **配色**（「配色」）: 内容・ブランドの色に合う 3 件（1 件目に「（おすすめ）」）＋`navy-brass`。同様。
3. **音声**（「音声」）: 読み上げ＋音楽＋効果音（既定・おすすめ。曲と効果音の組は内容から選ぶ）／
   読み上げ＋作曲した音楽と自作の効果音（自由の表現向け）／読み上げだけ／無音。音楽と効果音だけ（字幕で読む）は「その他」で受ける。
4. **表現**（「表現」）: 混在（既定・おすすめ）／部品だけ／自由（作り込む）。長さは聞かず、素材の量から標準（1〜2 分）を既定に決め、
   ユーザーが長さを言ったときだけ従う（4 問の上限のため。短め 30〜45 秒／標準 1〜2 分／長め 3〜5 分）。

背景は聞かず、`backgrounds.md` の選び方で内容から決める（ユーザーが背景を言ったときだけ従う）。
引数や会話で明示されている項目は聞かない。ユーザーのブランドの色があれば、配色は近いものを選び、台本で `colors` を上書きしない
（上書きの口は無い。近いテーマを選ぶ）。

## 指示のフォーム（order.py）の補足

- 見本の画面は初回に Chrome で撮って `~/.cache/motion-video/order/` に置く（数秒。Chrome が無ければ見本なし）。`--spec` で質問の定義だけ見られる。
- 結果の `spec` に入る項目: `player`・`theme`・`motion`・`expression`・`audio`・`brand`。`build` には作るときの引数 `args`、`embed`・`export` の要否、長さの目安。
