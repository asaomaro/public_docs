# VOICEVOX の話者とスタイル

VOICEVOX エンジン 0.25.2（2026-10-02 に確かめた）の話者 43 人・スタイル 127 種。エンジンの版で増減するので、最新は下の命令で確かめる。

```bash
curl -s http://127.0.0.1:50021/speakers | python3 -c "import sys,json; [print(s['name'], '／'.join(t['name'] for t in s['styles'])) for s in json.load(sys.stdin)]"
```

## 使い方

- 43 人とも `casts.json` のプリセットにいる（名前は `python3 kaisetsu.py --list-casts`。ずんだもんは `zundamon`、四国めたんは `metan` など）。スタイルは白上虎太郎が「ふつう」、後鬼が「人間ver.」、里石ユカが「つぼみ」、ほかは「ノーマル」。
- ほかのスタイルを使うときは `casts.json` に登場人物を足し、台本の `cast:` にその名前を書く。`speaker` と `style` は下の表の文字のとおりに書く（違うと、その旨のエラーで止まる）。
- `style` を省くと「ノーマル」になる。白上虎太郎・後鬼・里石ユカには「ノーマル」が無いので、必ず `style` を書く。
- `credit` を書いておくと、VOICEVOX で声を作ったときに締めに出る。
- 同じ話者の別のスタイル（ずんだもんの「ささやき」など）を場面で使い分けるなら、別の名前の登場人物として足す。立ち絵は `chars/<足した名前>/` を見るので、元のフォルダを写しておく。

```json
"ryusei_hot": {"name": "青山龍星", "color": "#3b6fb5",
               "voice": {"engine": "voicevox", "speaker": "青山龍星", "style": "熱血", "speed": 1.0},
               "credit": "VOICEVOX:青山龍星"}
```

利用規約とクレジットの書き方は話者（音声ライブラリ）ごとに違う。使う前に、VOICEVOX の公式サイトにある各話者の利用規約を読む（`assets.md`）。
