# 画面を見て採点する（別の目で見る）

`qa.py` が撮った見本の一覧（`<台本名>_qa/sheet.jpg`。左上に番号と時刻）を見て、視聴回数の多い実際の解説動画と並べても見劣りしないかを判定する。
**作った本人はしない。** 台本の `style:` が動画の型（書いていなければ `talk`）。型ごとの作りは `../yukkuri-kaisetsu/styles.json` と `research.md` の 12。

## 見方

1. まず一覧を、台本を読まずに通して見る。**止まった所**（何の絵か分からない・読めない・同じに見える・安っぽい）に印を付ける。
2. 次に、型の作り（下の表）と照らす。
3. 観点ごとに点を付け、3 点以下なら、何枚目の・何を・どう直すかを書く。

- **一覧は全部の画面ではない**（`qa.md` に、全部で何画面かが書いてある）。写っていない画面は採点しない。大事な画面（山場の数字・写真）が写っていなければ、そう書く
  （細部は、同じフォルダの 1 枚ずつの PNG を開いて確かめる。足りなければ、作った人に `--max-shots` を増やしてもらう）。
- **同じ欠点は、1 つの観点でだけ引く**。絵文字や色の丸の多さは A、絵柄のまざりは E、字や絵が隠れるのは C、立ち絵の大きさと位置は D。
- 点の目安: その観点の欠点がある画面が、写っている画面の 1 割までなら 4、3 割までなら 3、半分までなら 2、それより多ければ 1。

## 型ごとの、手本の作り

| 型 | 手本の画面 |
|---|---|
| `talk` 掛け合い | 大きな立ち絵が左右。背景の上に絵・写真・図。白い字に話し手の色の太い縁 |
| `zukai` 図解 | 紙の色の画面に、単純な形と短い名前の図。人物は肖像写真に名前と年。立ち絵は下の左右に小さく、字幕は白く透ける帯 |
| `list` 列挙 | 写真が画面いっぱい。右上に「2.〇〇」の札。下に暗い箱の字幕、その上の左右に立ち絵 |
| `panel` 資料の板 | 中央の白い板に、赤い見出し・挿絵・写真・短い言葉。板の両脇に立ち絵 |
| `story` 物語・怪談 | 場面の写真が画面いっぱい。右上に章の札。黒い帯に黄色い字 |
| `geki` 寸劇 | 場所の背景に、人の絵と立ち絵が立つ。頭の上に名札、そばに白い箱のせりふ。左上に場所の札 |
| `review` 比べる | 実物の写真が画面いっぱい。点数・値段が大きな数字。左上に段階の札 |

## 観点と点数（各 5 点）

5: 手本と並べても分からない　4: 小さな直しでよい　3: 直さないと見劣りする　2: 作り直す画面が多い　1: 成り立っていない

### A. 絵の中身

- **そのとき話していることを、絵が見せているか**。字幕と見比べて、関係の薄い飾りの絵になっていないか。
- **絵の種類が、題材に合っているか**。実在の人・物・場所は写真、しくみは図、人のふるまいは人の絵（いらすとや など）。
  何でも絵文字 1 個と名札で済ませていないか（色のついた丸を並べただけ・同じ絵文字の使い回しは 3 点以下）。
- 絵が、答えを先に見せていないか。
- **絵が正しいか**。関係はあるが、まちがって伝わる絵になっていないか（分子の話に原子の記号、砂ぼこりに竜巻、「青い」と言っているのに灰色の写真）。

### B. 変化

- 同じ構図（絵 2 つを矢印でつなぐ、など）が 3 枚より多く続いていないか。写真・図・寸劇・大きな数字・題の画面がまざっているか。
- 背景が、話の中身で替わっているか（最初から最後まで同じ背景は 3 点以下）。
- 山場（数字・種明かし・ツッコミ）の画面が、ほかより強いか（大きい字・寄り・色）。

### C. 読みやすさ

- 字幕・名札・画面の言葉が、縮めた一覧でも読めるか。字が絵や立ち絵に隠れていないか。字幕が 2 行に収まっているか。
- 字幕が、語の途中で折れていないか（「ティ／ンダル」「1910／年に」）。
- 名札と吹き出しが、どの絵のものか分かるか。画面の言葉は 1 画面に 2〜3 語か（文を書いていないか）。
- 絵が、立ち絵や字幕に大きく隠れていないか。

### D. 立ち絵と演技

- 表情・体・動きが、画面ごとに違うか（一覧で、同じ顔が並んでいないか）。せりふの気持ちに合っているか。
- 立ち絵の大きさと位置が、型に合っているか。話していない人が、反応しているか。
- 立ち絵が画面の内側（相手の方）を向いているか（外を向いている人がいれば、台本に `<名前>.facing: left` か `right`）。3 人以上なら、全員の名前が字幕に出ているか。

### E. 型との一致・仕上げの質

- 型の手本の作り（上の表）になっているか。字幕の形・札の位置・絵の置き方が、動画の中でそろっているか。
- 素材の質: 絵柄がまざりすぎていないか（1 画面の中に、写真と絵文字と線画が並ぶ）。写真が粗くないか。出どころの表記が絵に付いているか（写真）。
- 冒頭の画面（1〜2 枚目）で、何の動画かが分かるか（茶番から始まる台本 `intro: chaban` は、茶番の後の題の画面で分かればよい）。締めの画面があるか。

## 書く形（`<台本名>.qa.md` の「目で見る」の下に足す）

```markdown
### 見た結果（2026-10-03・1 回目）
- A 絵の中身: 3
- B 変化: 4
- C 読みやすさ: 4
- D 立ち絵と演技: 4
- E 型との一致・仕上げの質: 3
- 総合: 直す

直す所（大事な順）
1. [A] #5・#6・#8 色の丸を 2 つ並べただけの絵が続く。波の長さのちがいは、波の線を 2 本描いた図（@draw か、波の写真）にする。
2. …

よい所（残す所）
- …
```

- 総合は、5 つとも 4 点以上なら「通す」、そうでなければ「直す」。
- 直す所には、**何枚目の・何を・どう直すか**を書く。「もっと良く」のような指摘は書かない。
- 一覧から分からないこと（動き・切り替わり・音）は、採点しない。分からないと書く。
