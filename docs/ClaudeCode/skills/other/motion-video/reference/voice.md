# 声（VOICEVOX・用意した WAV）・配布用・書き出し

手順 3 で声を前もって作るとき、配布用の HTML を作るとき、YouTube・編集ソフト向けに書き出すときに読む。

## 声を前もって作る（公開する動画に）

- `--voicevox`: VOICEVOX（既定 `http://127.0.0.1:50021`、`--voicevox-url` で変える）で、ナレーションを**1 文ずつ** WAV にして埋め込む。
  長い文は字幕だけを読点で分け、声は 1 文のまま流す（字幕は、その声の中の読点の息継ぎの時刻で切り替わる。VOICEVOX が返す拍の長さから求める）。
  字幕ごとに声を分けると、文の途中で語尾が下がって切れ、間が空くため。
  話者は `audio.voice`（例: `{"speaker": "ずんだもん", "style": "ノーマル", "speed": 1.15}`。既定は四国めたん）。速さの既定は 1.1（説明の動画は 1.1〜1.2 が聞きやすい）。
  `audio.voice.engine` が `voicevox` なら、`--voicevox` を付け忘れても、VOICEVOX が動いていれば声を入れる（つながらなければ warn。その HTML はブラウザの声になる）。
- **文の中の英字・数字の前後の空白は、声に渡す前に詰める**（字幕はそのまま）。VOICEVOX は空白を読点と同じ息継ぎにするので、
  「pane を分けて」が「ペイン、を分けて」と切れ、「10 回」が「じゅう、かい」と読まれるため。台本は読みやすいように空白を入れて書いてよい。
- **声を作る前に `--readings` を見る**。英字のまま（`audio.pronounce` に読みを足す）・「開け」（「あけ／ひらけ」）など、
  読み違えやすい所に `!` が付く。かなの読みも 1 文ずつ出るので、固有名詞を目で確かめる。
  作った WAV は `<台本名>_voices/` に置き、同じ文・同じ話者は作り直さない。掛け合いのせりふは、`cast` の `voice.engine: "voicevox"` の人の分も作る。
- `--voices-dir`: 用意した WAV（PCM）を名前順に、ナレーションの字幕と掛け合いのせりふへ前から順に当てる（`--timeline` で字幕の数を確かめる）。
- 前もって作った声は、**場面の長さと字幕の時刻が声の長さで決まる**ので、表示の時間がどの環境でも正確になり、待ちが起きない。
  WebM で保存した動画にも声が入る。HTML は大きくなる（声 1 分で約 4 MB）。
- VOICEVOX の声は、プレイヤーの下にクレジット（「音声: VOICEVOX:ずんだもん」）が出る。用意した WAV は `audio.voice_credit` に書く。

## 配布用（`--dist`）

見る人に配る・公開するだけの HTML。⚙ の書き出し（WebM で保存・編集用の映像・音のトラック）を出さず、
その実行部（engine.js の `@export-begin`〜`@export-end`）も HTML に入れない。再生・字幕・音声・チャプターなどはそのまま。
減るのは十数 KB（HTML の大きさの多くは楽器の録音の音・画像・声）。自分で編集・書き出しに使う HTML は `--dist` を付けずに作る。

## 編集・投稿用に書き出す

YouTube に上げる・編集ソフト（YMM4・AviUtl）で仕上げると言われたら、**video-export スキル**を使う
（字幕 SRT/VTT・訳した字幕・チャプター・YMM4 の台本とプロジェクト・AviUtl の exo。映像と音はこのプレイヤーの ⚙ から書き出す）。

## ブラウザの声（前もって作らないとき）

- 速さは `audio.rate`（既定 1.1）。掛け合いの話し手ごとには `cast.<名前>.voice` の `pitch`・`rate`。読み上げが字幕の時間に収まらないときの待ちと、時間の表示の直しは `player.md`。
