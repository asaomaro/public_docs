# motion-video — 台本から、動画のように再生できる HTML を作る

同梱の `build.py`（Python3 / 標準ライブラリのみ）が、台本（JSON）・描画部（`engine.js`）・プレイヤーを 1 つの HTML にまとめる。
外部への依存は無い（書体は OS のもの、画像は data URI で埋め込む）。

- **描画は台本と時刻だけで決まる**。シーク・倍速・巻き戻しでも同じ画になり、同じ台本からは同じ動画になる。
- **表現は 3 つのモードから選ぶ**。どのモードでも、プレイヤー・時間割・字幕・音声は同じ仕組み（決定論的）。

| 表現（台本の `expression`） | 映像の作り方 | 向く場面 |
|---|---|---|
| `components` 部品 | 14 種の部品だけで組む。速く安く、毎回ぶれにくい | 定型の紹介・社内向け・短時間で |
| `mixed` 混在（既定） | 基本は部品。見せ場の 1〜3 場面だけ `custom` で描く | ほとんどの紹介・説明 |
| `free` 自由 | 場面ごとに `custom`（Canvas）か `dom`（HTML・SVG・CSS）で描く。**プレイヤー・時間割・字幕・音声だけを使い、中身は Claude が作る** | 作り込みたい紹介・公開する動画 |

- どの場面にも **重ねの層**（`overlays`: 注記・矢印・強調・スポットライト・バッジ・カーソル・OS 風の通知・
  破片・波紋・紙吹雪・判子・手書きの丸・蛍光ペン）と **カメラ**（`camera`: 寄る・引く・移る・傾く。型の名前でも書ける）を付けられる。部品の見た目を崩さずに演出を足す手段で、`custom` より先に使う。
- **字幕はナレーションから自動**で作り、場面の長さもナレーションの長さと部品の最低の長さから自動で決まる。
- **音楽と効果音も決定論的**。曲は「時刻 → 音符」で決まり（シークしても同じ所が鳴る）、章ごとに和音の進行が変わり、
  章の盛り上がり（1〜3）で楽器が増える。効果音は部品・重ねの層の出来事（項目が出る・線がつながる・通知・クリック…）に合わせて自動で鳴る。

## 手順

### 0. 素材を集める
- 何を紹介・説明する動画か、誰が見るか、元になる資料（README・docs・メモ・画面の画像）を会話とリポジトリから集める。
- 素材が足りなければユーザーに確認する（何を伝える動画か、が分からないまま作らない）。

### 1. 選ばせる（`AskUserQuestion` を 1 回、最大 4 問）
呼び出す直前に、本文テキストへ次の 2 つの表を**必ず全件**出す（選択肢に載らないものも見せるため）。
`python3 <skill_dir>/build.py --list` の先頭にも同じ一覧が出る。

| プレイヤー | 見た目 | 向く場面 |
|---|---|---|
| `cinema` シネマ | 操作部は映像の上に重なり、再生中は隠れる | 紹介動画・ティザー |
| `studio` スタジオ | 操作部は映像の下、チャプターの一覧を下に並べる | 製品紹介・説明（既定） |
| `presenter` プレゼンター | 横にチャプターの目次と説明 | 研修・講義・長めの解説 |
| `minimal` ミニマル | 細いシークバーと最小限のボタン。速度・字幕・音声・チャプターは「⋯」 | 記事への埋め込み・短い動画 |
| `kiosk` キオスク | 自動再生・繰り返し・音なしで始まる。操作部は触れたときだけ | 展示・受付の画面 |
| `theater` シアター | 暗い地に大きな映像、横に文字起こし（クリックでその位置へ・検索） | 講演・録画の公開・長い解説 |
| `slides` スライド | 章の終わりで止まり、「次へ：章の名前」で進む | 発表の場で話しながら送る |

| 配色 | 性格 |
|---|---|
| `navy-brass` 紺と真鍮 | 紺の地に真鍮とターコイズ。落ち着いた製品紹介 |
| `midnight` 真夜中 | 黒に近い地にシアンと紫。技術・開発者向け |
| `daylight` 日中 | 白い地に青。社内説明・研修・明るい紹介 |
| `paper` 紙 | 生成りの地に焦げ茶と明朝の見出し。語り・解説 |
| `mono` モノクロ | 白黒に赤ひとつ。強い主張・キーノート |
| `vivid` 鮮やか | 深い紫の地に明るい差し色と丸ゴシック。広報・イベント |

質問（header の例）:

1. **プレイヤー**（「プレイヤー」）: 内容に合う 3 件（1 件目に「（おすすめ）」）＋`studio`。`studio` が 3 件に入っていれば次点。
2. **配色**（「配色」）: 内容・ブランドの色に合う 3 件（1 件目に「（おすすめ）」）＋`navy-brass`。同様。
3. **音声**（「音声」）: 読み上げ＋音楽＋効果音（既定・おすすめ。曲と効果音の組は内容から選ぶ）／
   読み上げ＋作曲した音楽と自作の効果音（自由の表現向け）／読み上げだけ／無音。音楽と効果音だけ（字幕で読む）は「その他」で受ける。
4. **表現**（「表現」）: 混在（既定・おすすめ）／部品だけ／自由（作り込む）。長さは聞かず、素材の量から標準（1〜2 分）を既定に決め、
   ユーザーが長さを言ったときだけ従う（4 問の上限のため。短め 30〜45 秒／標準 1〜2 分／長め 3〜5 分）。

引数や会話で明示されている項目は聞かない。ユーザーのブランドの色があれば、配色は近いものを選び、台本で `colors` を上書きしない
（上書きの口は無い。近いテーマを選ぶ）。

### 2. 台本を書く
`python3 <skill_dir>/build.py --list` で部品と書き方を確かめ、台本（JSON）を書く。骨組み:

```json
{
  "title": "動画の題名（ページの見出しにも出る）",
  "description": "ページに出す一文",
  "lang": "ja",
  "player": "studio",
  "theme": "navy-brass",
  "brand": { "name": "右上に出す名前" },
  "transition": "fade",
  "audio": { "narration": true, "music": "calm", "sfx": true, "rate": 1.1,
             "pronounce": { "Sodashitsu": "ソダシツ" } },
  "chapters": [
    { "title": "章の名前", "desc": "チャプターの一覧に出す説明",
      "scenes": [ { "type": "title", "title": "…", "narration": "…" } ] }
  ]
}
```

- 同じ type を 3 場面続けない。
**動きの性格（台本の `motion`）** — 1 つ選ぶと、切り替え・文字の出方・演出の層・カメラの既定がまとまって決まる（場面の指定が優先）。
内容と見る人から Claude が決める（質問はしない。ユーザーが「ダイナミックに」「落ち着いて」等と言ったときはそれに従う）:

| `motion` | 切り替え（章の境目） | 文字（題名） | 演出・カメラ | 向く内容 |
|---|---|---|---|---|
| `gentle`（既定） | fade | 浮かぶ（カーソルで現れる） | なし | 研修・社内説明・手順 |
| `dynamic` | whip・push・突っ込む・上へ（円が開く） | 弾む（叩きつける・揺れる） | 題名に集中線と粒、言い切りで寄る | 製品の発表・告知・勢いのある紹介 |
| `playful` | 回る・箱・円・上へ（回る） | 波打つ（落ちてくる） | 題名と締めに紙吹雪 | 子ども・イベント・親しみやすい案内 |
| `cinematic` | fade・突っ込む（白く光る） | ぼけから（伸びから縮む） | 光の玉・光の筋・周りを暗く、ゆっくり漂う | ビジョン・物語・ブランド |
| `tech` | 乱れ・拭き取り・モザイク・帯（乱れ） | でたらめな文字から | 走査線・格子の床 | 技術・データ・開発者向け |
| `retro` | モザイク・ばらばら・縞・縦の帯（タイル） | 瞬いて点く（落ちて跳ねる） | 古いフィルム・網点、題名は手持ちのカメラ | 懐かしさ・ゲーム・昭和風・遊び心 |
| `elegant` | ぼけ・fade・色の幕（色の幕） | 字間が詰まる（同じ） | 光漏れ・きらめき、呼吸するカメラ・ピントが合う題名 | 高級感・ブランド・式典・招待 |
| `news` | 色の帯・押し出し・重なる・扉（色の帯） | 箱が走る（斜めに滑り込む） | レーダーの輪、言い切りで一瞬で引く | 速報・発表・社内報・数字の報告 |

- 切り替え（43 種）: `fade` `slide` `zoom` `cut` `wipe` `push` `slide-up` `slide-down` `iris` `blinds` `split` `whip` `spin` `flash` `glitch` `pixel` `squeeze` `zoom-through`
  `diagonal` `diamond` `spot`（場面の `origin` から）`cube` `page` `liquid` `dive`（前の場面の `focus` へ飛び込む）`tiles` `stripes` `clock`

  `mask` `marker` `drop` `zoom` `outline` `roll` `spin` `shadow` `flip` `rotate` `bounce` `box` `flicker` `words` `halves` `swing` `elastic` `tracking` `skew`。
- 演出の層（`fx`）: `particles` `stars` `bokeh` `rays` `speedlines` `grid` `waves` `gradient` `aurora` `plexus` `contour` `shapes` `blobs`
  `embers` `halftone` `warp` `pulse` `bubbles` `matrix`（部品の下）・`scanlines` `confetti` `vignette` `sweep` `noise` `rain` `snow` `film` `leaks` `spotlight` `sparkles`（上）。
- 動き方（場面か台本の `ease`・`order`）: 緩急 `smooth`（既定）・`spring`・`snappy`・`bouncy`・`elastic`・`calm`、現れる順 `reverse`・`center`・`edges`・`random`・`alternate`・`zigzag`（項目を順に出す部品に効く）。
  `"fx": false` で性格の既定も止める。1 場面に 1〜2 個まで。
- カメラの型（`camera` に名前）: `push-in` `pull-out` `pan-left` `pan-right` `rise` `punch` `tilt` `drift` `dolly` `crash-zoom` `orbit` `pan-reveal` `rack-focus`（ぼけから合う）`breathe` `sink` `handheld`。
  自分で書くときも、鍵の点に `blur`（px）を書けばピントが動く。
- 画面の揺れ: `"shake": [{"at": 0.4, "amp": 18, "dur": 450}]`（`slam`・`impact`・`countdown`・判子は自動で揺れる）。
- 強い動き（`slam`・揺れ・破片・`flash`・`glitch`）は見せ場だけに使う。全場面を強くすると、どれも強調にならない。

**ナレーション（＝字幕）の書き方**

- 1 場面に 1〜2 文。話し言葉で、1 文は 34 字前後まで。字幕は 1 行に約 34 字（字の大きさは映像の幅に比例するので、映像の大きさによらない）。
  34 字を超える文は、文の中ほどの読点で字幕が 2 つに分かれる。分けられない文は 2 行に折り返し（行の長さはそろう）、`--timeline` と作るときに警告が出る。
- **説明に合わせて動かす**: 項目が順に現れる部品（`bullets`・`steps`・`cards` など）は、項目の数とナレーションの文（字幕）の数が同じなら、
  i 番目の項目を i 番目の文を話し始める時に出す（`sync: "auto"`。既定）。文の数を項目にそろえて書くのが基本（配列の `narration` が書きやすい）。
  数が違っても文に合わせるなら `sync: true`（余った項目は最後の文の間に）、場面の長さへの均等な割り付けにするなら `sync: false`（場面か台本の最上位に書く）。
  重ねの層は `atCue`・`untilCue`（n 番目の文が始まる・終わる時。1 から）、`custom` は `H.cue(i)`・`H.cueEnd(i)`。
  `at` の割合（0..1）を `--timeline` の字幕の位置から見積もって書くやり方は、ナレーションを書き直すとずれるので使わない。
  `custom` で文の時刻が要るときは `s._cues` を直に読まず `H.cue(i)` を使う（`s._cues` も直した後の時刻に書き換わるが、`H.cue` が正式な口）。
  時刻は声の長さ（前もって作った声）や、ブラウザの声の速さの直しの後の時刻なので、声が遅くても速くても文と動きがずれない。
  動き・音楽の速さは変えない（伸び縮みさせると不自然なため）。合わせるのは「いつ出すか」だけ。
- `narration` を配列で書くと、要素ごとに別の字幕になる（句点の無い短い文がつながって 1 つの長い字幕になるのを防ぐ）。
- 画面の文字とナレーションを同じにしない（画面は要点の語、ナレーションは説明の文）。
- `**強調**` は字幕では外れ、画面の部品では強調色になる。
- 読み上げで誤読しやすい語（製品名・英字のコマンド）は `audio.pronounce` に読みを入れる（字幕は元の表記のまま）。
- 場面の長さは自動（`duration` を書くと上書き。ナレーションが収まらなければ警告が出る）。

**音楽と効果音を選ぶ**（一覧は `python3 <skill_dir>/build.py --list-sounds`、聞き比べるページは `--sounds -o sounds.html`）

- 曲（`audio.music`）は内容と雰囲気から 1 つ選ぶ。毎回同じ曲にしない。目安:

| 内容・雰囲気 | 曲の例 |
|---|---|
| 会社・サービスの紹介（定番） | `corporate` `bright` `trust` `pitch` `clean` |
| 新製品・発表・告知 | `launch` `innovate` `keynote` `hype` `startup` |
| 技術・開発者・データ | `tech` `data` `circuit` `ai` `robot` `synthwave` `hacker` `cyber` |
| 落ち着いた解説・研修 | `calm` `study` `lofi` `rain` `documentary` `minimal` |
| 課題の提示・危機 → 解決 | 章ごとに `tension` / `mystery` → `hope`（章の `music` で切り替える） |
| 物語・ビジョン・壮大 | `epic` `hero` `wonder` `trailer` `adventure` `space` |
| 明るい・楽しい・子ども | `happy` `pop` `kids` `summer` `island` `musicbox` |
| 和・アジア・民族 | `wa` `kyoto` `matsuri` `zen` `ryukyu` `orient` `celtic` |
| レトロ・ゲーム | `chiptune` `arcade` `puzzle` `rpg` |
| 大人・店舗・夜 | `jazz` `bossa` `cafe` `night` `soul` `house` |
| 力強い・スピード | `rock` `drive` `sport` `funk` `countdown` |

- 効果音の組（`audio.sfx.kit`）: `standard`（既定）・`soft`（研修・医療・子ども）・`digital`（技術・SaaS）・`retro`・`organic`（手作り・生活）・
  `cinematic`（予告・ビジョン）・`playful`・`wa`（和）・`news`（報道・レポート）・`minimal`（章・通知・クリックだけ）。曲の雰囲気と揃える。
- 量（`audio.sfx.density`）: `low`（章・通知・クリック・数え上げの終わり等だけ）・`normal`（既定。項目が出る・線がつながる等も）・`high`（表の行まで）。
  読み上げのある 2 分以上の動画で、うるさく感じそうなら `low`。
- 盛り上がり: 章ごとに 1〜3（既定は最初と最後が 1、最後の手前が 3、ほかは 2）。山場の章に `"energy": 3`。
- 場面ごとに足す・止める: 場面の `"sfx": [{"at": 0.5, "name": "ding"}]`・`"sfx": false`・`{"map": {"appear": "bubble"}}`。
  重ねの層は `"sfx": false` か `"sfx": "効果音の名前"`。読み上げ中は音楽が自動で下がる（`audio.duck`）。
- 表現が `free` で、音も作り込むと決めたとき（質問で「作曲・自作」を選んだとき）:
  - 曲は `{"preset": "…", 上書き}` で既存の曲の一部（`bpm`・`key`・`scale`・`prog`・`layers`・`drum`）を変えるか、
    `layers`（楽器 × 型）を一から組む。さらに自由にするなら `{"bpm": 96, "src": "music.js"}`（小節ごとに音符を返す JS）。
  - 楽器（`audio.instruments`）・効果音（`audio.sfxDefs`）は層（発振器・雑音・包絡・フィルタ）の並びで作る（書き方は `--list-sounds` と `audio.js` の冒頭）。
  - `custom` の場面の中で `H.sfx(ms, "名前か出来事")` を呼べば、その時刻に鳴る（条件の外で呼ぶ）。
  - 自作しても、時刻だけで決まる作りは同じ（`Math.random` は使わず `M.rand`）。

**モードごとの書き方**

- `components`: 部品と `overlays`・`camera` だけで組む。`custom` は使わない（使うと警告が出る）。
- `mixed`: 部品で組み、「部品では伝わりにくい見せ場」（画面の変化の様子・複数の画面の並び・独自の図）だけ `custom` にする。
  まず `overlays`・`camera` で足りないかを考え、足りないときに `custom`。
- `free`: 各場面を `custom` で描く。部品は `H.sub(type, spec, lt, d, {x, y, scale})` で縮小して並べる道具として使ってよい。
  ただし `title`・`end` は部品のままでもよい。

**dom（HTML・SVG・CSS で自由に描く）**

- `src`（HTML）・`cssSrc`（CSS）・`updateSrc`（毎コマ呼ぶ JS。本体 `(el, lt, d, H, s)`）を台本からの相対パスで書く（`html`・`css`・`update` に直接でもよい）。
- 1920×1080 の箱に描き、舞台の大きさに合わせて縮む。時刻は CSS 変数 `--lt`（場面の経過 ms）と `--p`（0..1）で受け取る。
- **CSS のアニメーションは一時停止にして、遅れを `--lt` で与える**（`animation-play-state: paused; animation-delay: calc(var(--lt) * -1ms)`）。
  こうすればシーク・倍速でも同じ画になる。JS で動かすなら `update` で `lt` から決める。
- `dom` の場面は、シークバーのプレビューと「WebM で保存」には映らない（Canvas だけが対象）。見せ場に使い、全場面を `dom` にしない。

**custom（Canvas に自由に描く）**

- 本体 `(ctx, lt, d, H, s)`。`lt` は場面の中の経過 ms、`d` は場面の長さ ms、`s` は台本の場面、`H` は描画の道具
  （一覧は `python3 <skill_dir>/build.py --api`、手本は `recipes.md`、実物は `examples/scenes/*.js`）。
- JS は **`src` に .js のパス**（台本からの相対）で書くのが基本。短いものは `code` に文字列か行の配列。
- 場面の共通の項目の名前（`type` `narration` `duration` `transition` `anim` `ease` `order` `sync` `camera` `overlays` `fx` `bg` `mark` `markText`）は、
  部品でも `custom` でも設定として読まれる。`custom` の独自のデータには別の名前（`data`・`items` など）を使う（`order` に配列を書くとエラーになる）。
- 緩急は `H.P(lt, a, b, H.eio)` のように渡す。`H.lin(lt, a, b)` は進みそのもの（形が違う）で、等速の緩急は `H.linear`。
- **時刻だけで決まる描き方にする**（`Math.random` → `H.rand(種)`、`Date.now`・前のコマの状態・DOM の操作は使わない）。
- 座標は 1920×1080。大事な文字は縦 120〜880 に収める（下は字幕）。色は `H.C` の配色だけ。
- 長いデータ（行・名前の配列・部品の spec）は台本の場面 `s` に置き、JS は描き方だけにする。

### 3. 確かめて作る

```bash
python3 <skill_dir>/build.py spec.json --timeline      # 場面の長さ・字幕の時刻・合計（HTML は作らない）
python3 <skill_dir>/build.py spec.json -o out.html      # HTML を作る（--player / --theme で上書き可）
python3 <skill_dir>/build.py spec.json --voicevox       # VOICEVOX でナレーションの声を前もって作って埋め込む
python3 <skill_dir>/build.py spec.json --voices-dir voices/   # 用意した WAV を名前順に字幕へ当てて埋め込む
```

**声を前もって作る（公開する動画に）**

- `--voicevox`: VOICEVOX（既定 `http://127.0.0.1:50021`、`--voicevox-url` で変える）で、ナレーションを字幕の単位ごとに WAV にして埋め込む。
  話者は `audio.voice`（例: `{"speaker": "ずんだもん", "style": "ノーマル", "speed": 1.0}`。既定は四国めたん）。
  作った WAV は `<台本名>_voices/` に置き、同じ文・同じ話者は作り直さない。掛け合いのせりふは、`cast` の `voice.engine: "voicevox"` の人の分も作る。
- `--voices-dir`: 用意した WAV（PCM）を名前順に、ナレーションの字幕と掛け合いのせりふへ前から順に当てる（`--timeline` で字幕の数を確かめる）。
- 前もって作った声は、**場面の長さと字幕の時刻が声の長さで決まる**ので、表示の時間がどの環境でも正確になり、待ちが起きない。
  WebM で保存した動画にも声が入る。HTML は大きくなる（声 1 分で約 4 MB）。
- VOICEVOX の声は、プレイヤーの下にクレジット（「音声: VOICEVOX:ずんだもん」）が出る。用意した WAV は `audio.voice_credit` に書く。

**編集・投稿用に書き出す（`--export`）** — YouTube に上げる・編集ソフトで仕上げると言われたとき

```bash
python3 <skill_dir>/build.py spec.json --voicevox --export youtube            # 字幕・チャプター
python3 <skill_dir>/build.py spec.json --voicevox --export all --win-dir "C:\Users\me\Videos\intro_export"   # ＋YMM4・AviUtl
```

| 種類 | 書き出すもの（`<台本名>_export/`） |
|---|---|
| `youtube` | 字幕 `<題>.ja.srt`・`.vtt`（掛け合いは「名前：せりふ」）／概要欄に貼る `youtube_description.txt`（チャプターの時刻・クレジット。YouTube の条件＝3 章以上・各 10 秒以上を外れると警告）／訳す元 `subs.ja.txt` |
| `ymm4` | ゆっくりMovieMaker4 の台本 `<題>_ymm4_script.csv`（A 列キャラクター名・B 列セリフ。「台本ファイルを開く」で読み、YMM4 のキャラクターの声・立ち絵で作り直す）／映像・音楽・効果音・声・字幕を層に並べた `<題>.ymmp`（実験的） |
| `exo` | AviUtl（拡張編集）の `<題>.exo`（映像・音楽・効果音・声（話し手ごとの層）・縁取りの字幕。Shift_JIS） |

- **映像と音はプレイヤーから書き出す**（音楽・効果音はブラウザで合成するため）。HTML の ⚙ の
  「編集用の映像（字幕・音なし WebM）」（1920×1080。1 倍速で録るので動画の長さだけかかる）と
  「音のトラックを書き出す（WAV）」（`_voice`・`_music`・`_sfx`・`_mix` の 48kHz WAV。録らずにすぐ作る）を、`<台本名>_export/` に置く。
  どちらも台本どおりの時間割で書き出すので、`--export` の字幕・プロジェクトと時刻がそろう。
- 声は前もって作った声（`--voicevox`・`--voices-dir`）だけが WAV とプロジェクトに入る（`voices/` に集める）。ブラウザの読み上げの声は書き出せない。
  **公開する動画は前もって声を作る**。
- **ほかの言語の字幕**: `subs.ja.txt`（1 行に字幕 1 つ）を Claude が訳して、同じ場所に同じ行数の `subs.en.txt` などを書き、もう一度 `--export youtube` すると `<題>.en.srt`・`.vtt` ができる。
  YouTube の多言語の音声トラックにするには、その言語の声（WAV）で別に作り直す。
- YMM4・AviUtl は Windows の絶対パスで素材を探す。Windows 以外で作るときは `--win-dir` に、書き出したフォルダを置く Windows の場所を渡す。
  `--fps`（既定 30）でプロジェクトのフレームレートを変える。AviUtl で WebM を読むには L-SMASH Works などの入力プラグインが要る。
- `.ymmp` は YMM4 の公開されていない形式に合わせて書く（実験的）。開けない・崩れるときは、CSV の台本を YMM4 で読み、映像（WebM）と音（WAV）を手で置く。
- 渡すときは `README.txt`（何をどこに置くか）も一緒に伝える。

- `--timeline` で、合計の長さが選んだ長さに収まるか、字幕の切れ方が不自然でないかを見る。直すのは台本だけ。
- エラー（不明な type・必須の項目の欠け・画像が無い）は台本を直してから作り直す。
- 作ったら 1 回だけ開いて見る（場面の文字のはみ出し・重なり）。直すのは台本の文言・項目の数・`custom` の JS で、`engine.js` は触らない。
- `custom` の場面は、シークして途中の画を 2〜3 点見る（時刻だけで描けていれば、どこから見ても崩れない）。

### 4. 渡す
- 出力した HTML の場所を伝える。`SendUserFile` で渡すと確かめやすい。
- 声を前もって作らなかったときは「読み上げの声は見る人のブラウザと OS のものを使う（声が無い環境では効果音と音楽だけ）」と一言添える。
  VOICEVOX で作ったときは、音声ライブラリ（キャラクター）ごとの利用規約とクレジットの表記を確かめるよう添える。

## プレイヤーの操作（全テンプレート共通）

| 操作 | ボタン | キー |
|---|---|---|
| 再生・一時停止 | ▶／❚❚、映像のクリック | `Space`・`K` |
| 停止（最初に戻る） | ■ | `S` |
| 5 秒戻る・進む | シークバー | `←`・`→` |
| 前・次のチャプター | ⏮・⏭、チャプターの一覧 | `[`・`]` |
| 速度（0.5〜2 倍） | 選択欄 | `<`・`>` |
| 字幕のオン・オフ | 字幕 | `C` |
| 音声のオン・オフ | スピーカー | `M` |
| 音量 | スピーカーの横のつまみ | `↑`・`↓`（10% ずつ） |
| 小窓で再生（ピクチャー・イン・ピクチャー） | 画面の中に小さな画面のアイコン（対応するブラウザだけ） | — |
| 全画面 | ⛶ | `F` |

- 操作部は常に 1 行。長いチャプター名は … で省略し、省略したときはツールチップで全部を出す。映像の側が狭いときは、
  チャプター名 → 音量のつまみ → 停止 → 前・次のチャプター → 小窓 → 速度 → チャプターのメニューの順に隠す（キー操作やほかの場所に代わりがあるものから）。
- シークバーはチャプターごとに区切られ、触れると時刻とチャプター名が出る。キーボードでも操作できる（`Home`・`End`・`PageUp/Down`）。
- 速度・字幕・音声・音量・書体の選択は、見る人のブラウザに保存される。
- 読み上げは、再生・倍速に合わせて字幕の区切りごとに話す。シークしたときは次の字幕から話す。
- **読み上げが字幕の時間に収まらないときは、読み終わるまで動画がその位置で待つ**（声の速さは OS とブラウザで違うため）。
  一時停止・シーク・停止で待ちは解け、声が無い環境では待たない。待たせたくない（映像の時間を優先する）ときは `audio.wait: false`。
- **ブラウザの声の速さに合わせて時間の表示を直す**: 話し終えた字幕から実際の長さを測り、まだ来ていない場面の長さ・字幕の時刻・
  合計の時間・チャプターの時刻を直す（最初の 1〜2 文の後から合う）。測った速さは声ごとにブラウザに覚え、次からは最初から合った時間で始まる。
  そのため、ブラウザの声のときは、同じ台本でも見る環境によって合計の時間とチャプターの時刻が変わる。止めるときは `audio.adapt: false`。
  前もって作った声（上記）では直さない（もともと正確）。
- 場面の長さの見積もりは、`audio.pronounce` で置き換えた後の読み方の文字数で数える（読みが長くなる語も含めて見積もる）。

## プレイヤーの機能（全テンプレート共通）

- **シークバーのプレビュー**: 触れた時刻の画を小さく描く（描画が時刻だけで決まるので、その場で 1 コマ描ける）。
- **文字起こし**: `theater` で横に出る。クリックでその位置へ、検索で絞り込み。
- **続きから再生**: 前回の位置を見る人のブラウザに覚え、次に開いたとき「前回の続き（m:ss）から再生」を出す。
- **設定（⚙）**: 字幕の大きさ（小・標準・大）、表示（プレイヤーの操作部・一覧・メニューの色。テーマのまま・ライト・ダーク・システム＝OS の設定に従う。映像の中はテーマの色のまま）、書体（映像の文字・字幕・プレイヤーの文字（チャプターの一覧・メニュー・設定・文字起こし。時刻などの等幅は除く）。テーマの既定・ゴシック・明朝・丸ゴシック・UD・メイリオ・教科書体のうち、見る人の OS に入っているものだけ出る）、音楽・効果音の入り切り（見る人のブラウザに保存）、**動画ファイル（WebM）で保存**
  （最初から 1 倍速で再生しながら録画。字幕は映像に焼き込み、音楽と効果音は入り、読み上げの声は入らない）、
  **編集用の映像**（字幕・音なし・1920×1080 の WebM）、**音のトラックを書き出す**（声・音楽・効果音・全部を別々の WAV に。`--export` を参照）。
- **キー**: `J`・`L` で 10 秒、`0`〜`9` で 0〜90% の位置へ（上の表の操作に加えて）。
- **1 ページに複数のプレイヤー**: 1 つを再生すると、ほかは止まる。

## 掛け合い（登場人物・せりふ）

```json
"cast": {"zunda": {"name": "ずんだもん", "color": "#5fae45", "side": "right", "height": 520,
                   "images": {"normal": {"closed": "chars/z/normal.png", "open": "chars/z/normal_open.png", "blink": "chars/z/normal_blink.png"}, "smile": "chars/z/smile.png"},
                   "voice": {"pitch": 1.35, "rate": 1.15}}},
"castAlways": true,
"chapters": [{"title": "導入", "scenes": [{"type": "talk", "board": {"type": "bullets", "items": ["…"]}, "bg": "bg/room.png",
  "lines": [{"who": "zunda", "text": "解説するのだ！", "face": "smile", "emote": "!", "voice": "voices/001.wav", "shake": true, "pause": 0.5}]}]}]
```

- `lines` のある場面では、登場人物が左右に立ち、話している方が弾んで口が動き、ほかの方は少し薄くなる。まばたきする。字幕は話し手の色の帯と名札で映像に描く。
- 口は、`voice`（WAV）があれば音量に合わせて、無ければ文字の拍で動く（どちらも時刻だけで決まる）。`voice` のある場面は WAV の長さで時間を割り付ける。
- 画像が無い登場人物は、仮のキャラクター（`color` の丸顔。smile・surprised・angry を描き分け）で描く。
- `castAlways: true` なら、掛け合いでない場面にも登場人物を出したままにする（締めの `end` を除く）。
- 声が無いせりふはブラウザの読み上げで、`cast.<名前>.voice` の `pitch`・`rate` で話し手ごとに変える。

## メモ

- コマンドは `python3` で書いている。Windows で `python3` が無ければ `py -3`（または `python`）で同じように動く。
- `title`・`end`・`logo` の紋章の中の 1 文字は、既定で題名の頭の字。`markText` で変えられる（例: `"markText": "G"`）。
- 画面の比率は 16:9（1920×1080 の座標で描き、表示の大きさに合わせて拡大縮小する）。
- `image` の画像は data URI で埋め込むので、画像が多い・大きいと HTML が大きくなる。
- 読み上げの声が無い環境（例: 声の入っていない Linux）では、効果音と音楽だけになり、その旨がプレイヤーの下に出る。
- 絵文字のアイコン（`bullets` の `icon`）は OS の絵文字の書体で描く。絵文字の書体が無い環境では四角になる。
- 見本: `examples/data-tour.json`（時間とともに動くデータと画面の解説。画像は `examples/assets/`）・`examples/depth-type.json`（立体・奥行きの部品と文字の演出・切り替え depth/swing・演出の層 cubes）・`examples/dynamic.json`（動きの性格 dynamic・動きの強い部品・切り替え・文字の出方・演出の層・新しい重ねの層）・`examples/showcase.json`（追加した部品・切り替え・`dom` の場面をすべて使う。`theater`）・`examples/sodashitsu.json`（部品だけ）・`examples/sodashitsu-mixed.json`（混在。pane が割れて増える・ブラウザと端末版の並び・
  SSH の線・OS 風の通知・カメラ・注記を `custom` と `overlays` で）。
- **楽器の音**: 曲の旋律・和音・リズムは `audio.js` で作り、ピアノ・電気ピアノ・弦・合唱・ハープ・マリンバ・ギター・ベース・管楽器・
  琴・尺八・三味線など 35 の楽器は、録音した楽器の音（`samples.py`。FluidR3_GM、Frank Wen、CC BY 3.0）で鳴らす。合成の音のままの楽器
  （シンセ・8bit・パッド・打楽器のほとんど）はそのまま。作るときに、曲が使う楽器の使う音域だけ（4 半音おき）を埋め込む
  （1 楽器 300 KB 前後。1 曲で 0.5〜1.5 MB 増える）。録音の音は初回に取りに行き `~/.cache/motion-video/samples/` に置いて使い回す
  （オフラインで作るなら先に `python3 <skill_dir>/samples.py` で全部取っておく。取れなければその楽器は合成の音で鳴る）。
  クレジット（「楽器の音: FluidR3_GM（Frank Wen、CC BY 3.0）」）はプレイヤーの下に自動で出る。合成の音だけにするなら `audio.samples: false`。
  `--sounds` の聞き比べのページは合成の音のまま。
- 音の定義は `sound.py`（曲・効果音・効果音の組・出来事）、合成は `audio.js`（楽器・打楽器の型・和音と旋律の作り方）。
  曲や効果音を足すときは `sound.py` に 1 つ足す（楽器・型・打楽器の型を足すときは両方）。`--sounds` のページで聞いて確かめる。
- 音楽の音声ファイルを使うなら `"music": {"file": "bgm.mp3"}`（埋め込むので HTML が大きくなる。権利に注意）。
- テーマを足すときは `build.py` の `THEMES` に 1 つ足す（canvas の配色・書体・背景の模様・操作部の配色）。
- 部品を足すときは `engine.js` の `R.<type>` と、`build.py` の `SCENE_TYPES`（必須の項目・説明・例）と `MIN_SEC` に足す。
