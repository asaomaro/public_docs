# irasutoya — いらすとやのイラストを探して取る

いらすとやには約 25,000 の記事（絵は 1 記事に 1〜十数枚）がある。全部は落とさず、**その場で探し → 見本を見て選び → 選んだものだけ取る**。
同梱の `irasutoya.py`（Python3 と Pillow・vtracer）が、サイトの Blogger のフィードを読む。

```
ほしい絵を言葉にする → search（言い換えをまとめて） → 見本の一覧画像を Read で見る → （セットなら show で中身を見る）→ get → 取った絵を Read で確かめる
```

## サイトの検索の性格（ここが要）

検索は、**記事の題・説明文・カテゴリーに、その字がそのまま書いてあるか**だけを見る。意味では探せない。だから Claude が言い換えを用意する。

| 性格 | 例 | どうするか |
|---|---|---|
| 表記が違うと別の言葉 | 「うさぎ」5 件・「ウサギ」・「兎」は別。「ハサミ」32 件・「はさみ」5 件 | `"うさぎ\|ウサギ\|兎"` と `\|` でまとめる |
| 説明文の言い回しで当たる | 「困る 会社員」0 件 →「困っている 会社員」15 件。「怒る」より「怒っている」 | 動詞は「〜している」「〜した」の形も入れる |
| 英語では当たらない | `cat` 1 件、`idea` 0 件 | 日本語で探す（`AI` のように日本語の文に出る英字は当たる） |
| 同じものに別の呼び名 | 「リモートワーク」2 件・「テレワーク」13 件・「在宅勤務」12 件 | 別の引数に分けて一度に探す |
| 抽象的な言葉は弱い | 「グラフ 上昇」1 件・「右肩上がり」4 件 | 絵に描かれているもの（人・物・しぐさ）の言葉に直す |

書き方: 空白 = どちらも含む、`|` = どれかを含む（空白より先に組になる。`会社員 困っている|焦る` =「会社員」かつ「困っている か 焦る」）、空白と `-言葉` = 含まない。

## 手順

### 0. 準備（最初の 1 回）

```bash
python3 <skill_dir>/irasutoya.py check                # Pillow と vtracer が入っていれば知らせる。無ければ入れ方を出して止まる
python3 -m pip install --user pillow vtracer          # 無かったとき
```

| 入れるもの | 使うところ |
|---|---|
| Pillow | 見本の一覧画像（`--sheet`）と `canvas` で、絵を並べる・縮める・部品に切り分ける |
| vtracer | `canvas`・`trace` で、PNG の輪郭をなぞって SVG にする（`canvas --raster` なら要らない） |

`externally-managed-environment` と出る環境では `--break-system-packages` を足す（Pillow は `sudo apt install python3-pil` でもよい）。入れてよいか分からない環境ではユーザーに聞く。
探す（`search`）・取る（`get`）だけなら、どちらも無くて動く。

### 1. ほしい絵を決める
- 何に使うか（資料・スライド・動画・ブログ…）、**商用か**（下の「決まり」。分からなければ聞く）、保存する場所（既定はカレントの `images/`）。
- 文章や台本に合う絵を任されたら、場面ごとに「誰が・何を・どうしている」を 1 行で書き出す。それが探す言葉の元になる。

### 2. 探す

```bash
python3 <skill_dir>/irasutoya.py search "ひらめいた|ひらめき|閃いた" "アイデア|アイディア" --sheet
python3 <skill_dir>/irasutoya.py search "困っている|悩んでいる|焦る" --label 会社 -n 20 --sheet
python3 <skill_dir>/irasutoya.py search --label 猫 --label 冬          # カテゴリーだけで見る
python3 <skill_dir>/irasutoya.py labels                                # カテゴリー 239 個の一覧
```

- 引数 1 つが 1 回の検索。**言い換えは 1 回目から 2〜3 個の引数に分けて出す**（別々に探して 1 つの一覧にまとまり、題に言葉が出るもの・いくつもの検索に当たったものが上に来る）。
- `--label` はカテゴリーで絞る（何度でも書け、全部に入るものだけになる）。「サーバー」でウォーターサーバーが混ざるようなときに `--label コンピューター`。
- `-n` 出す件数（既定 12）、`--max` 1 つの言葉でサイトから取る件数（既定 60）。
- `★N 枚セット` は、1 つの記事に絵が何枚も入っている（表情違い・色違い・男女など）。「中身」に 1 枚ずつの説明が出る。
- 0 件・外れのとき: 表記を変える → 言い回しを変える → 上位の言葉（「柴犬」→「犬」）→ **見た目が似た別の事柄**（「胃腸炎」→「食中毒」）→ 2 枚に分けて組み合わせる（「パドルボード」＋「おじいさん」）。
  3 回変えても無ければ、無いと伝えて近い候補を出す（いらすとやに無い絵はある）。

### 3. 見て選ぶ
- `--sheet` で、番号つきの見本を 1 枚に並べた画像ができる（既定 `~/.cache/irasutoya-skill/sheet.png`）。**必ず Read で開いて、絵を見て選ぶ**。題だけで決めない（題が合っていても、構図・人数・向き・雰囲気が合わないことがある）。
- セットの記事は中身を見る:

```bash
python3 <skill_dir>/irasutoya.py show 3 --sheet      # 3 番目の記事の絵を、1 枚ずつ番号つきで
```

- ユーザーに選んでもらうときは、見本の一覧画像の場所と、候補の番号・題・記事の URL を示す。任されているなら自分で選び、選んだ理由を一言で添える。

### 4. 取る

```bash
python3 <skill_dir>/irasutoya.py get 1 3:2 --dir images          # 1 番目と、3 番目の記事の 2 枚目
python3 <skill_dir>/irasutoya.py get 5 --as idea                 # images/idea.png という名前で
python3 <skill_dir>/irasutoya.py get 3:1,4                       # セットの 1 枚目と 4 枚目（全部は 3:all）
python3 <skill_dir>/irasutoya.py get https://www.irasutoya.com/2024/06/blog-post_21.html     # 記事の URL でも
```

- 番号は**直前の `search`** の結果を指す。`show` をしても番号は変わらない。別の `search` をすると入れ替わるので、選んだらすぐ取る。
- 既定は元の大きさ（長い辺 400〜1000px ほどの、背景が透明な PNG）。小さくてよければ `--size 400`。これより大きい絵はサイトに無い（高解像度は有償）。
- `<保存先>/credits.json` に、題・記事の URL・元の画像の URL が残る（yukkuri-kaisetsu の `images/credits.json` と同じ形なので、そのまま動画のクレジットに出る）。
- 取ったら **Read で 1 回開いて**、頼まれた絵になっているかを確かめる。

### 5. 渡す
- 保存した場所、それぞれの絵の題と記事の URL、いま何点か（`count`）を伝える。
- 商用かもしれないときは、下の決まりのうち当てはまるもの（20 点・再配布）を一言で添える。

```bash
python3 <skill_dir>/irasutoya.py count --dir images     # 取った点数（同じ絵は 1 点）
```

## Canvas で動かす（motion-video の動画に入れる）

取った PNG を **SVG（ベクトル）にして**、**Canvas に描いて時刻で動かす JS** に変える。motion-video の `custom` の場面にそのまま入り、ほかの Canvas でも使える。
Canvas に描くので、motion-video の「WebM で保存」とシークバーのプレビューにも映る（Chrome で、SVG を描いた Canvas を録画できることを確かめた）。

```bash
python3 <skill_dir>/irasutoya.py canvas images/idea.png images/presen.png -o scenes/idea.js --split --preview
```

| できるファイル | 中身 | 扱い |
|---|---|---|
| `scenes/idea.js` | 絵（data URI）＋描く道具＋描き方を 1 つにしたもの。台本に `{"type": "custom", "src": "scenes/idea.js", "duration": 6}` | **開かない**（絵のデータで数百 KB ある） |
| `scenes/idea.draw.js` | 描き方（数行）。最初はひな形ができる | **ここを直す** |
| `scenes/idea.preview.html` | 動きだけを見る画面（`--preview`）。`?t=1200` でその時刻に止まる | 確かめる用 |

- 絵の名前は、拡張子を除いたファイル名（`idea`）。`src` は台本から見た相対パスで書く。まわりの透明な余白は落とす（`--no-trim` で残す）。
- **描き方を直したら** `python3 <skill_dir>/irasutoya.py canvas --update scenes/idea.js`（絵はそのまま、描き方だけ入れ直す。`--preview` も付けられる）。
  絵を足す・替えるときは `-o` で作り直す（`*.draw.js` は残る）。

### SVG にするか、PNG のままにするか

既定は SVG。色の塊ごとに輪郭をなぞるので、**塗りのざらつき・ぼかし（頬の赤み）・細い模様（髪のしま）は平らな色になる**。

| | SVG（既定） | PNG のまま（`--raster`） |
|---|---|---|
| 大きさ | 元の PNG の 2〜4 割（1 枚 40〜300 KB） | 1 枚 300〜600 KB（長い辺を 800px に縮めて） |
| 拡大・カメラで寄る | 輪郭が荒れない | ぼやける |
| 質感 | 平らな塗りになる | 元のまま |

- `--detail fine`（既定）は元に近い。`--detail mid` は半分ほどの大きさだが、猫のしま・画面の文字のような模様が減る。それより粗くはしない（絵が崩れる）。
- **作ったら元の PNG と見比べる**（`--preview` の画面を開くか、下の Chrome の 1 行で撮って Read で見る）。顔の表情・大事な模様が変わって、
  元の絵の印象が保てていなければ `--raster` にする（質感が大事な絵・大きく映さない絵は PNG のままがよい）。
- SVG のファイルそのものがほしいとき（Canvas 以外で使う）は `python3 <skill_dir>/irasutoya.py trace images/idea.png`（`images/idea.svg`。出どころは credits.json に引き継がれ、点数は増えない）。

### 部品に分ける（`--split`）

背景が透明な絵を、**つながっていない塊ごと**に分ける（人物と吹き出し、並んだ物、飛んでいる記号など）。分けた部品は別々に出したり動かしたりできる。

- 部品の番号は大きい順。`部品の一覧`（既定 `~/.cache/irasutoya-skill/parts.png`、`--sheet` で場所）を **Read で開いて、どの番号が何かを見る**。
- 分け方の調整: `--gap`（この px までのすき間は同じ部品。既定 3）、`--min-part`（全体のこの % より小さい塊は近くの部品に入れる。既定 1.5）、`--max-parts`（既定 8）。
- つながっている絵（腕と体、顔と目）は分かれない。腕だけ・口だけを動かすことはできない（絵そのものの描き替えは、このスキルではしない）。

### 描き方（`*.draw.js`）

`(ctx, lt, d, H, s)` の本体の続きとして動く。`draw(名前, {…})` が 1 枚を描き、動く前の枠 `{x, y, w, h}` を返す（文字を添える位置に使える）。
motion-video の道具（`H.txt`・`H.cue(i)`・`H.sfx` など）もそのまま使える。**時刻 `lt` だけで姿が決まる**書き方にする。

```js
H.txt("ひらめきを、伝える", 960, 170, { size: 64, weight: 800, align: "center", color: H.C.ink });
draw("idea", { x: 560, y: 560, h: 520, at: 300, enter: "rise", idle: "breathe", shadow: true,
               parts: { 2: { at: H.cue(1), enter: "pop", idle: ["float", "pulse"] } } });     // 吹き出し（部品 2）は 2 文目で出す
var b = draw("presen", { x: 1340, y: 560, h: 520, at: 2600, enter: "right", idle: "sway", wave: .6, shadow: true });
if (b && lt > 3400) H.txt("説明する", b.x + b.w / 2, b.y + b.h + 60, { size: 34, align: "center", color: H.C.muted });
```

| 項目 | 意味 |
|---|---|
| `x` `y` | 絵の中心（既定 960, 540）。`h` か `w` で大きさ（既定 `h: 520`） |
| `at` `enter` `enterDur` | 出る時刻 ms・出方・かける長さ（既定 0・`pop`・600）。出方: `none` `fade` `pop` `zoom` `drop` `rise` `left` `right` `spin` |
| `out` `exit` `exitDur` | 去る時刻・去り方（出方と同じ名前を逆向きに。既定 `fade`）・長さ（既定 400）。`out` を書かなければ居つづける |
| `idle` | 居るあいだの動き。名前か、名前の並び: `float`（上下にふわふわ）`sway`（左右に揺れる）`breathe`（息づかい）`bounce`（跳ねる）`shake`（震える）`pulse`（脈打つ）`nod`（うなずく）`spin`（回る） |
| `amp` `speed` | 動きの強さ・速さ（既定 1） |
| `wave` | 足もとを止めて、上ほど大きく横にゆらす強さ（0.5〜1.5。旗・草・炎・のんびりした人に） |
| `flip` `rot` `alpha` `shadow` `pivot` | 左右反転・傾き（度）・濃さ・足もとの影・動きの軸（既定は足もと。`"center"` で中心） |
| `stagger` `order` `partEnter` | 部品を 1 つずつ出す間隔 ms・順（`"size"` 既定・`"left"` `"right"` `"top"` `"bottom"`・番号の並び）・出方（既定 `pop`） |
| `partIdle` | 部品ごとの動き（部品の中心を軸に、少しずつずれて動く） |
| `parts` | 部品ごとの指定 `{番号: {at, enter, idle, out, exit, amp, speed, wave, dx, dy, hide}}` |

- 動きは控えめにする。説明の動画では、出方 1 つ＋居るあいだの動き 1 つで足りる。全部の絵を同時に強く動かさない。
- 作ったら **`--preview` の画面を開いて動きを見る**（Chrome があれば
  `google-chrome --headless=new --window-size=960,540 --virtual-time-budget=1500 --screenshot=shot.png "file://…/idea.preview.html?t=1200"` で、その時刻の絵を Read で見られる）。
  プレビューには motion-video の道具が無いので、`H.txt` などは映らない（絵の動きだけを見る）。動画の中での見え方は motion-video で作って確かめる。
- 絵のデータは HTML に埋め込まれる。絵そのものを取り出せる形で配ることになるので、**公開・配布するのは録画した動画（WebM）にする**（下の決まり）。
- 動かすのは「元の印象を保つ加工」の範囲にする。部品を外して別の意味にする・攻撃的な動きにする、はしない。

## いらすとやの決まり（2026-10-02 に、ご利用について・よくあるご質問を確かめた）

使い方がこれに当たりそうなときは、取る前にユーザーに伝える。決まりは変わることがあるので、迷ったら https://www.irasutoya.com/p/terms.html と https://www.irasutoya.com/p/faq.html を読み直す。

- 個人・法人・商用・非商用とも無料。著作権は放棄されていない（作者: みふねたかし）。**クレジットの表記は不要**（入れるなら「いらすとや」）。
- **商用は、1 つの制作物に 20 点まで**（同じ絵の重複は 1 点。表情違いは別々に 1 点ずつ。色違いはまとめて 1 点）。21 点からは有償（全体の点数 × 1,100 円が目安）。
  - YouTube はサムネイルを含めて 1 本 20 点（収益化していなければ制限なし）。ウェブは 1 サイト 20 点（記事が増え続ける無料のサイトは 1 記事 20 点）。
  - 社内だけで使う資料・その場限りのプレゼンは、仕事でも非商用の扱い。ただし外から制作費をもらって作るものは商用。
- **素材としての再配布は不可**（加工しても不可）。絵そのものを集めて配る・売る、スタンプやグッズの主役にする、画像編集アプリの素材に入れる、はできない。
  → 取った絵を、素材の形のまま公開のリポジトリに入れない。配るのは、絵を一部に使った制作物（資料・動画・記事）にする。
- 使えない用途: 公序良俗に反するもの、攻撃的・差別的・性的・過激な使い方、アダルト、選挙運動や特定の個人・団体への批判、誹謗中傷のアカウント、LINE スタンプ。
- 加工は、元の印象を保つ範囲で可（色を一部変える・白黒・組み合わせる）。いらすとやの絵と分からなくするための加工は不可。
  SVG にするのも加工に当たる。質感が平らになるので、元の絵と見比べて印象が保てているものだけ使う。ベクターデータは配布元でも販売していないので、作った SVG を素材として配らない。
- 使ってよいのは irasutoya.com に素材として載っている絵だけ（このスキルはそこからだけ取る）。

## サイトへの配慮

- **まとめて落とさない**。必要な絵だけを取る（全件の取得・カテゴリーごとの一括取得はしない。`:all` は 1 つの記事の中だけ）。
- スクリプトは、サイトへの問い合わせを 1 秒あけ、同じ検索は 1 日だけ手元（`~/.cache/irasutoya-skill/`）から返す。新しく載った絵を探すときだけ `--fresh`。
- robots.txt は空で、規約にもプログラムからの取得を禁じる項は無い（2026-10-02）。それでも、同じ検索を何度も繰り返さず、言い換えは 1 回にまとめる。

## 仕組み（直すときのために）

| すること | 読む場所 |
|---|---|
| 言葉で探す | `https://www.irasutoya.com/feeds/posts/default?alt=json&q=<言葉>&max-results=<件数>`（本文つき。`label:名前` で絞れる） |
| カテゴリーだけで見る | `.../feeds/posts/default/-/<カテゴリー>/<カテゴリー>?alt=json`（1 回 150 件まで。`q` を付けると絞り込みが外れる） |
| 記事の URL から | `.../feeds/posts/default?alt=json&path=/2024/06/blog-post_21.html` |
| カテゴリーの一覧 | `.../feeds/posts/summary?alt=json&max-results=0` の `category` |
| Canvas で動かす | `sprite.js`（描く道具のひな形）に、絵の data URI と `*.draw.js` を差し込む。部品に分けるのは `split_parts()`（透明でない画素のつながりを行ごとにたどる）。SVG にするのは `trace_svg()`（vtracer。細かさは `DETAIL`）で、部品に分けてから 1 つずつなぞる |
| 画像 | 本文の `<a href="…/s800/name.png"><img alt="説明">`。`/s800/` を `/s0/`（元の大きさ）・`/s200/`（長い辺 200px）に差し替えられる |

- サイトの「あいまい検索」は Google のカスタム検索（ブラウザで動く）で、スクリプトからは使わない。言い換えは Claude が作る。
- フィードの形が変わって取れなくなったら、上の URL を `curl` で読んで `entry()` の読み方を直す。
