# yukkuri-publish — 題・概要欄・サムネイルを作る

yukkuri-kaisetsu が動画と一緒に書き出す `<台本名>.info.json`（章の時刻・クレジット・画像の出どころ）と、
yukkuri-script の `<台本名>.facts.md`（出典）から、公開まわりを作る。

## 手順

### 1. 題を決める

台本の約束（`<台本名>.outline.md` の 1 文）から、型を変えて 3 案を出し、1 つを台本の `title:` に書く。

| 型 | 例 |
|---|---|
| 問い | 空はなぜ青いのか？答えは「6 倍」にあった |
| 意外な事実 | 夕焼けが赤い理由、空が青い理由と同じだった |
| 数 | 知らないと恥ずかしい空の色の雑学 3 選 |
| 短い言い切り＋主題 | 答えられる大人、ほぼ 0 人。「空が青い理由」 |
| キャラクターと学ぶ | ずんだもんと学ぶ「空が青い理由」 |

- 大事な言葉を前に。28 字前後までが検索結果で見える（40 字を超えると warn）。
- かっこ書きは、ゆっくりなら頭に `【ゆっくり解説】`、ずんだもんなら末尾に `【ずんだもん解説】`・`【ずんだもん＆四国めたん解説】` が多い
  （YouTube で視聴回数の多い 40 本の題を見た結果。`../yukkuri-kaisetsu/research.md` の 10）。
- **題で約束したことに、動画が答えていること。** 動画に無いことをあおらない。事実と違う数字・言い切りを書かない。

### 2. 台本の先頭に書き足す

```text
title: 空はなぜ青いのか？答えは「6 倍」にあった【ずんだもん解説】
summary: 空が青い理由と、夕焼けが赤い理由は、じつは同じ仕組みです。光の散らばり方を 5 分で説明します。
tags: ずんだもん, 四国めたん, 解説, 科学, 雑学
thumb: 空が青い | 本当の理由 | 6倍！？
thumb_faces: zundamon=surprised+, metan=smug
```

- `summary`: 概要欄の最初の 1〜2 文。何がわかる動画かを書く（最初の 100 字ほどが検索結果に出る）。
- `thumb`: サムネイルの文字。`|` で改行、3 行まで。**1 行 6 字前後・全部で 12 字ほど**の強い一言にする。題の言い換えで、同じ文にしない。
  行ごとに黄・白・赤で描く。数字・「！？」・短い名詞が効く。
- `thumb_faces`: サムネイルの表情（書かなければ、聞き手は驚き・解説役は得意げ）。`thumb_bg`: 背景（書かなければ台本の `bg`）。
  `thumb_font`: フォント（`dela` 極太ゴシック・`mochiy` 丸いポップ体・`reggae` 飾り文字・`rounded_black` 丸ゴシック。一覧は `../yukkuri-kaisetsu/fonts.json`）。

### 3. 作る

```bash
python3 ../yukkuri-kaisetsu/kaisetsu.py 台本.txt --voicevox   # まだなら。題を変えたら作り直す
python3 <skill_dir>/publish.py 台本.txt                       # 台本.description.txt と 台本.thumbnail.png
```

- サムネイルは 1 回開いて見る（`Read`）。文字が立ち絵の顔にかかっていないか、小さくしても読めるか、文字が多すぎないか。
- `warn:` が出たら直す（題が長い・章が 3 個より少ない・summary が無い・出典が無い・VOICEVOX のクレジットが無い・HTML のままでは配れない BGM）。

### 4. 公開の前に確かめる（使う人に伝える）

- [ ] **動画の形**: YouTube には、プレイヤーの「WebM で保存」で書き出した動画を上げる。HTML は、埋め込んだ素材を取り出せるので配らない
  （立ち絵・背景・BGM の多くは、素材としての再配布を禁じている）。
- [ ] **クレジット**: 概要欄に `VOICEVOX:ずんだもん` の形で、使ったキャラクター全員ぶん。立ち絵の作者、BGM、背景、画像の作者とライセンス。
- [ ] **出典**: 概要欄の「出典・参考」。時点で変わる話は、いつ時点かを動画の中で言っている。
- [ ] **キャラクターの規約**: 個人や団体への非難、政治・宗教、わざと誤解させる内容、公序良俗に反する内容は不可。東方（霊夢・魔理沙）は二次創作であることを書く。
- [ ] **収益化するとき**: 立ち絵・BGM・背景・声のそれぞれが、収益化を認めているか（`../yukkuri-kaisetsu/assets.md` の確認表）。ゆっくりボイス（AquesTalk）は使用ライセンスが要る。
- [ ] **量産型のコンテンツと見なされないこと**（YouTube の収益化の決まり。2025-07-15 改称）: 動画ごとに 切り口・構成・つかみ・締め・背景・BGM を変える。
  調べた中身と自分の見方を入れる。同じ型の動画を短い間に続けて上げない。概要欄をきちんと書く。
- [ ] **AI の開示**: AI で書いた台本、合成音声のキャラクター、アニメ調の立ち絵は、YouTube の「改変または合成されたコンテンツ」の開示の対象外。
  実在の人や出来事を本物のように見せる映像・音声を入れたときだけ、開示が要る。
- [ ] **目次**: 概要欄の目次は 0:00 から、3 個以上、各 10 秒以上で、YouTube のチャプターになる。

## メモ

- サムネイルは 1280×720 の PNG。立ち絵は台本の `cast` の 2 人（集めた立ち絵か、台本の隣の `chars/`）。立ち絵が無い登場人物は描かない。
- フォントは `../yukkuri-kaisetsu/fonts/`（`python3 ../yukkuri-kaisetsu/fetch_assets.py --only fonts` で取る。どれも SIL Open Font License）。無ければ Noto Sans CJK で代わる。
