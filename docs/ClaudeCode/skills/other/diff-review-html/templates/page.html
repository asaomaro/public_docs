キー操作

j / k差分の行を移動（↓ / ↑ も同じ）
c / Enterその行にコメントを書く
Escコメント欄を閉じる（書きかけは残る）
Ctrl/⌘ + Enterコメントを確定（未提出として溜める）
e前後の行を展開（Shift+E でそのファイルを全部）
trich 表示 ↔ source 表示の切り替え
fそのファイルの折りたたみを切り替え
sunified 表示 ↔ split 表示の切り替え
[ / ]左（ファイル一覧）／右（コメント一覧）へ移動（畳んでいれば開く）
{ / }左／右のペインを畳む・戻す（Shift + [ / ]）
rレビューの提出パネルを開く
?この一覧を開閉

ペインの境界にフォーカスを合わせると、← → で幅を変えられます （Shift 併用で大きく・Home / End で最小 / 最大・Enter で畳む）。
