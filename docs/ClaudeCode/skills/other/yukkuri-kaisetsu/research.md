# 立ち絵スタイルの解説動画の調査（2026-10-02）

ゴール: テーマを与えるだけで、既存のゆっくり解説・ずんだもん解説と同じ水準の動画ができること。
そのために、画面・構成・掛け合い・素材・声・規約を調べ、スキルに足すものを決める。

## 調べ方と限界

- 読んだもの: 制作者の解説記事（note・ブログ）、公式のキャラクター設定と規約、公開されている台本、既存の自動生成ツールの README とプロンプト、YouTube の公式ヘルプ。
- **人気動画そのものは見ていない。** YouTube から動画や字幕を機械的に取ることは規約上の懸念があるので、していない。下の数値は「制作者がそう書いている」値で、実際の動画を測った値ではない。
- 記事は同じ著者（note の SS@ゆっくり編集効率化）とツール販売元に偏っている。
- ページは要約を経て読んでいるので、規約の文言を実装の根拠にする所は、原文をもう一度読む（とくに効果音ラボの再配布の例、けいふぉんとのライセンス）。
- 「出どころなし」と書いた項目は、一般論か推測。

## 3. 構成

- **型**（10 分の例）: 冒頭 0:00〜0:30 つかみ（問い・意外な事実。200 字）→ 0:30〜1:00 結論のチラ見せ → 背景 → 本題 3 つ前後（1 つ約 800 字。結論→理由→例→結論）→ 意外な補足 → まとめ（要点 3 つ・200 字）→ 締め。
- **冒頭**: 最初の 10〜15 秒で決まる。1〜2 行目で「この動画で何がわかるか」を言い切る。「今日は〜について解説します」から始めない。
  あいさつは短く、問いから入る（「ねえ魔理沙、日本で一番売れた飲み物って何か知ってる？」）。冒頭の約束は本編で必ず果たす（ずれると大量に離脱する）。
- **長さ**: 8 分以上で途中の広告が入れられる。解説は 8〜15 分が多い。5 分 1,500〜1,800 字、10 分 3,000〜3,500 字、15 分 4,500〜5,300 字。
- **1 せりふ**: 20〜40 字（ツールによって 35・40・70 字）。10 分で 90〜150 せりふ。
- **中だるみ対策**: 中盤に豆知識・クイズ、聞き手と話し手の入れ替え、「答えは後半で」の予告、カウントダウン。
- **締め**: 感謝・登録と高評価・コメントへの問いかけ・次回予告・小さなオチ の中から。毎回同じにしない。
- **ショート**: フック 2 秒 → 問題 8 秒 → 答え 20 秒 → 裏づけ 22 秒 → 次の行動 8 秒。あいさつなし。最後が最初につながるように書く。60 秒で 250〜350 字。
- **タイトル**: 28 字前後。数字・疑問形・「〜を知らないと損」「〜の真実」。サムネは赤・黄・黒の 3 色、12 字ほど。
- **概要欄**: 目次（0:00 から、3 個以上、各 10 秒以上）・出典・クレジット（`VOICEVOX:ずんだもん`、`立ち絵：坂本アヒル 様`、`BGM：曲名（作曲者 / 配布元）`）。

### キャラクター

| キャラ | 一人称 | 相手の呼び方 | 口調 | 役 |
|---|---|---|---|---|
| ゆっくり霊夢 | 私 | 魔理沙 | 〜よ・わ・ね・なの？・だわ | 聞き手。視聴者の代わりに疑問を出す。ときどきズレたことを言う |
| ゆっくり魔理沙 | 私 | 霊夢 | 〜だぜ・なんだぜ・だよな・じゃないか | 解説とツッコミ |
| ずんだもん | 僕（ボク） | めたん・つむぎ（呼び捨て） | 〜のだ・なのだ。敬語なし | 聞き手にも解説にもなる（出どころで割れる）。不憫な目にあう |
| 四国めたん | わたくし | ずんだもん・つむぎさん | お嬢様風のタメ口。〜かしら・わよ・わね | 解説かツッコミ。ツンデレ気味・金欠・中二病 |
| 春日部つむぎ | あーし | めたん先輩・ずんだもん先輩 | ギャル。語尾の公式指定なし | — |

- ほかのキャラの一人称と呼び方は、VOICEVOX 公式の「呼び方」のページに全員分の表がある（`https://voicevox.hiroshiba.jp/dormitory/<id>/calls/`）。そのままデータにできる。
- 「のだ」の規則: 「である」に言い換えられる所は「なのだ」、「んです」に言い換えられる所は「のだ」。
  「のだよ」「のだね」「なのだぞ」「ですのだ」は使わない。疑問は「〜のだ？」。せりふの 7〜8 割が「のだ」で終わる。
  毎回付けると不自然、まったく無いと視聴者が違和感を持つ。
- LLM の典型の失敗: 一人称が「私」になる、魔理沙が「です」で話す、「〜なのだけど」、全せりふが同じ長さ。

### 型

- 基本の回し方: 聞き手が問う → 解説 → 聞き手が驚く・言い直して確かめる → 解説がツッコむか補う。
- 解説 3〜5 せりふごとに、聞き手を 1〜2 回。軽いツッコミは 30〜60 秒に 1 回。茶番は多くて 2 往復。
- 聞き手のせりふは 相づち・質問・ツッコミ の 3 種。相づちを固定しない（「へぇー」「えっ、そうなの？」「それって本当？」「〜ってこと？」）。
- **同じ型（説明→確認の質問→肯定）を 3 回続けない。** 聞き手の的外れな予想や大げさな反応を全体で 3 回以上入れる。せりふの長短に差をつける。
- 専門用語は、聞き手に質問させてから答える。数字には比べる相手を付ける。
- 定番: 「○○ってよく聞くけど、結局なに？」→「簡単に言うと、△△のことなんだぜ。」／
  「つまり○○すれば全部解決ってことね！」→「そんな単純な話じゃないぜ。」
- あいさつ: 「ゆっくり霊夢です」「ゆっくり魔理沙だぜ」。「ゆっくりしていってね」は冒頭に置く例と締めに置く例がある。

## 5. 自動生成が人手の動画に負ける点と対策

| 負ける点 | 対策 |
|---|---|
| 内容が薄い（検索すれば出る言葉の羅列） | 先に調べて「へぇ」となる点を 3〜5 個、出典つきで選ぶ。独自の問いを立てる |
| 誤情報 | 出典つきの事実の一覧を先に作り、台本はそれだけを根拠に書く。確かめられないことは入れない。説が分かれることはそう言う。書いたあと出典と突き合わせる（別の工程で） |
| 相づちと型の繰り返し | 上の「型」の規則を台本の検査にする |
| 冒頭が弱い・あおりと中身がずれる | 1〜2 行目で利点を言い切る。約束と本編が合っているかを検査する |
| 画面が止まる・同じ表情が続く | 場面の長さに上限（冒頭 5〜8 秒、本編 60 秒）。せりふごとに表情と板を決める。数字は、その数字を言うせりふで出す |
| 読み間違い | 読みの欄を持つ。合成の前に VOICEVOX の読みを出して確かめる。英字はカタカナに置き換える（字幕は元のまま） |
| 毎回同じ構成 | 導入を短く、役の入れ替え、締めを変える |

参考になる既存のツール:
- `seiji1097g-cell/zundamon-metan-videos`（Claude のスキル。調査→構成→台本→図をコードで描く→確認→MP4→出典との見直し。1 せりふ 35 字以内、3〜4 せりふごとに変化を入れる）
- `Ken-kichi/video-pipeline`（台本・スライド・読み上げを別々に「生成→採点→修正」。視聴データの反省がプロンプトに入っている）
- `tumf/movie-generator`、`motemen/markdown-to-zundamon`

## 6. 本編の画像

テーマだけから自動で集めるのに、規約と技術の両面で使えるもの（おすすめ順）:

1. **コードで描く図（グラフ・年表・比較表・地図・図解）＋ OSS のアイコン・絵文字**（Twemoji CC BY 4.0、Noto Emoji、Material Symbols Apache 2.0、Tabler Icons MIT）。規約の論点が無く、HTML に埋め込んで配れる。
2. **Wikimedia Commons API**。認証なし。`extmetadata` から作者・ライセンスを取ってクレジットを自動で作れる。PD・CC0・CC BY に絞る。連絡先入りの User-Agent が要る。
3. **Openverse API**。`attribution` がそのまま使える。匿名は 1 日 200 回ほど。
4. **NASA Images API・ジャパンサーチ（`f-rights=cc0,pdm,ccby`）・国の資料（PDL1.0、出典の表記が必須）**。宇宙・歴史・統計のテーマに。

自動では使えないもの:
- 写真 AC・イラスト AC・ぱくたそ: プログラムでのダウンロードを規約で禁じている。
- いらすとや: API なし。商用は 1 作品 20 点まで。再配布は不可。
- Unsplash: 直リンクが必須で埋め込みと両立しない。API は自動化を対象にしていない。
- Pixabay・Pexels: API はあるが、大量の自動取得と素材単体での配布は不可。

引用（他人の写真・スクリーンショット）: 公表済み・必然性・明瞭な区別・主従・必要最小限・出所の明示。雰囲気づくりの背景としては使えない。

## 7. 声・効果音・フォント

- **ゆっくりボイス**: 霊夢 = AquesTalk1 の女性 1（f1）、魔理沙 = 女性 2（f2）。Linux 版の .so があり、Python の ctypes から呼べる。漢字の文には AqKanji2Koe が要る。
  無償は個人の非営利だけ。評価版はナ行・マ行が「ヌ」になる。個人の開発ライセンスは 1,980 円（製品ごと）、収益化には年 6,380 円の使用ライセンス。
  ライブラリは同梱も自動ダウンロードもできないので、**使う人が自分で入手した .so を指定する任意の機能**にする。作った音声は公開してよい。
- **VOICEVOX**: 既定は話速 1.0・抑揚 1.0・前後の無音 0.1 秒。読みは `/user_dict_word`（辞書）と `/accent_phrases?is_kana=true`（かなとアクセントの指定）で直せる。
  スタイル（ずんだもん: あまあま・ツンツン・ささやき・ヒソヒソ・ヘロヘロ・なみだめ）は感情に合わせて切り替えられる。クレジットは `VOICEVOX:ずんだもん`。
- **クレジットなしにしたいとき**: AivisSpeech Engine（VOICEVOX と同じ API、Docker、ポート 10101）。
- **効果音**: 効果音ラボは動画での利用は自由だが、**ツールに既定の素材として入れること・動画テンプレートに入れて配ることは再配布として禁じている**。
  スキルには入れられない。既定は今の合成音のまま、使う人が自分で落としたファイルを名前に割り当てる方式にする。HTML は配らず WebM にする。
- **フォント**: Google Fonts にある OFL のフォントを、使う文字だけにして埋め込む。字幕は M PLUS Rounded 1c か Zen Maru Gothic、見出しは Dela Gothic One か Mochiy Pop One。
  定番のけいふぉんと・ラノベ POP は Google Fonts に無い（ラノベ POP の規約は読めていない）。コーポレート・ロゴは OFL。

## 8. YouTube の決まり

- 2025-07-15 に「繰り返しの多いコンテンツ」が「量産型のコンテンツ」に改称。テンプレートで大量生産に見える AI 生成コンテンツ、解説の乏しい画像スライドショーは収益化できない。
  導入と締めが同じでも、大部分が動画ごとに違えばよい。
- 停止されたチャンネルに多いとされる特徴: 最初から最後まで同じ背景、立ち位置が固定、投稿者の視点がない、短期の連投、概要欄が短い（個人の記事）。
- AI で書いた台本、アニメ調の立ち絵は「改変・合成コンテンツ」の開示の対象外。実在の人物や出来事を本物のように見せる場合だけ開示が要る。
- キャラクターの規約: 個人や団体への非難、政治・宗教、意図的な虚偽、公序良俗に反する内容は不可（ずんだもん・四国めたんの音源規約、東北ずん子のガイドライン）。
  東方の二次創作は、二次創作であることの明記が要る。

## 残っている不確かさ

- 立ち絵の位置と大きさ、画像の大きさ、見出しの位置、せりふの間、画面が変わる間隔は、実際の人気動画で測った値が無い。
  確かめるには、参考にしたい動画を何本か決めて、画面のスクリーンショット（人が撮ったもの）から測る。
- ずんだもんとめたんのどちらが解説役かは、出どころで割れている。両方選べるようにする。
- 字幕の大きさ（45・80・160px）、BGM の音量、話速は記事ごとに幅がある。
- 読めなかった規約: OtoLogic、ニコニ・コモンズ、ラノベ POP、春日部つむぎの公式の規約ページ。

## 10. 視聴回数の多い動画の題と長さ（2026-10-02）
