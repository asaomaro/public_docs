# 素材（立ち絵・声・BGM）と規約

このスキルは素材を同梱しない。使う人が入手した素材を読み込む。**素材ごとに利用規約があり、配布者・作品ごとに違う**。
下の内容は確かめる観点の案内で、規約そのものではない。公開・収益化の前に、必ず各配布元の最新の規約を読む。

## 立ち絵

| 置き場所 | 名前 | 中身 |
|---|---|---|
| `chars/<名前>/` | `<表情>.png` | 口を閉じた絵（`normal` は必須。無ければ仮のキャラクター） |
| | `<表情>_open.png` | 口を開いた絵（口パクに使う） |
| | `<表情>_half.png` | 半開き（任意） |
| | `<表情>_blink.png` | 目を閉じた絵（まばたきに使う。任意） |
| | `<表情>@<ポーズ>.png` ほか | ポーズつきの絵（`smile@raise.png`・`smile@raise_open.png` …。任意） |
| `chars/<名前>/` | `sprite.json` と `sprite/` | パーツの形（体の絵と、重ねる表情・まばたき・口のパーツ）。`psd_export.py`・`parts_export.py`・`sprite.py` が書く。あれば PNG より優先 |

- 背景が透明な PNG にする。高さは揃える（表示の高さは `casts.json` の `height`、既定 520px 相当）。
- PSD で配られている立ち絵は、表情・口・目の組み合わせごとに書き出す。PSDTool 形式の PSD は
  `python3 <skill_dir>/psd_export.py 立ち絵.psd --recipe <skill_dir>/recipes/<名前>.json --out chars/<名前>`（`pip install psd-tools` が要る）。
- パーツ画像のフォルダ（キャラ素材・YMM4 の「動く立ち絵」）は `python3 <skill_dir>/parts_export.py <フォルダ> --out chars/<名前>`
  （preset.ini の表情から自動。無ければ `--recipe`）。
- 差分つき立ち絵の配布元・レシピ・規約の要点は `recipes/README.md`。VOICEVOX の 43 人と霊夢・魔理沙は、スキルの `chars/` に書き出してある
  （`.gitignore`。別の環境では `recipes/README.md` の配布元から取り直す）。台本の隣の `chars/<名前>/` が優先される。
- 立ち絵ごとの定義は `recipes/<名前>.json`（どのレイヤー・パーツで、どの表情・体を作るか。`smile#2`・`raise#2`・`point+mic` のように同じラベルの形をいくつも書ける。
  `levels` に度合い、`desc` に説明。説明を書かなければ、使うパーツの名前から作る）。ラベルの説明は `labels.json`。
  ある表情・体は `kaisetsu.py --list-casts`、形ごとの説明と度合いは `kaisetsu.py --list-casts <名前>` で見られる。
- 動画には台本で使った表情の絵だけが埋め込まれる（表情を多く使うと HTML が大きくなる。パーツの形なら、ポーズ 1 つで 0.2MB ほど・表情は数 KB〜数十 KB。サンプルの台本で 4MB ほど（うち 2MB 余りはプレイヤーと音楽の楽器の音））。
- VOICEVOX の話者は、エンジンに入っている絵を `python3 <skill_dir>/portraits.py`（`--all` で全員、`--out` で置き場所）で
  `chars/<名前>/styles/ポートレート.png` に取り出せる（`normal.png` が無いときは `normal.png` にも置く）。1 人 1 枚で口・目の差分は無い。
  スタイルごとの絵は `styles/`、規約の案内は `policy.txt`。
  取り出した画像は再配布に当たらないよう、リポジトリに入れない。
- 確かめること:
  - キャラクターそのものの利用規約（例: ずんだもん・四国めたんなどは、キャラクターの利用のガイドラインがある。
    霊夢・魔理沙は原作の二次創作のガイドラインと、ゆっくり素材の配布者の規約の両方）。
  - 立ち絵の作者の規約（加工・商用・収益化・クレジットの要否）。クレジットは台本の `<名前>.credit:` に書くと締めに出る。

## 声

| 方法 | 使い方 | 確かめること |
|---|---|---|
| VOICEVOX | 起動しておき `--voicevox`（話者は `casts.json` の名前とスタイル。選べる話者の一覧は `speakers.md`） | 音声ライブラリ（キャラクター）ごとの利用規約。多くはクレジット表記（「VOICEVOX:ずんだもん」など）が必要で、締めに自動で出る |

| ゆっくりボイス（Windows で作る） | `--yukkuri-bat` で `<台本名>_yukkuri.bat` を書く → Windows で実行 → できた `<台本名>_yukkuri/` を `--voices-dir` で渡す | Wine が使えない環境向け。AquesTalkPlayer の規約は上と同じ |
| 用意した WAV | 名前順に並べて `--voices-dir`（WAV・PCM） | 作ったソフトと声の規約（YMM4 などで作ったゆっくりボイスの WAV も、これで使える） |

- **AquesTalkPlayer を Wine で動かす準備**: ① https://www.a-quest.com/products/aquestalkplayer.html の Win 版を取り、`aquestalk/aquestalkplayer/` に展開する。
  ② Wine を用意する（`apt install wine` か、管理者権限が無ければ、展開するだけで動く版を `~/.local/share/yukkuri-wine/` に置く。
  この環境では Kron4ek/Wine-Builds の `wine-11.18-amd64-wow64` を、公開されている sha256 と照らして使った）。場所は環境変数 `AQUESTALK_WINE` でも指定できる。
  画面（WSLg など。`DISPLAY`）が要る。話速は、AquesTalkPlayer のプリセットの一覧に `kaisetsu_f1_115` のような行を足して指定している。
| ブラウザの読み上げ | 何も付けない | 見る人の環境の声になり、動画ファイルの録画には入らない。試しや下書き向け |

## 背景

`backgrounds.json` に 59 枚（名前・説明・出どころ）。台本の `bg:`・`@bg:` に名前を書く。一覧は `python3 <skill_dir>/kaisetsu.py --list-assets`。
画像は `bg/`（1920×1080 の JPEG。リポジトリには入れない）。無い環境では `python3 <skill_dir>/fetch_assets.py` で配布元から取り直す。

| 出どころ | 何を | 規約の要点（2026-10-02 に確かめた） |
|---|---|---|
| みんちりえ https://min-chi.material.jp/ | 教室・部屋・和室・神社・街・屋上 など 52 枚、流線 6 枚 | 動画・商用・加工は可、クレジットは不要（表記の希望あり）。素材としての再配布は不可 |
| OKUMONO https://sozaino.site | 青空・草原・満月・星空・グラデーション | 動画（収益化の制限なし）・商用・加工は可、クレジットは不要。素材としての再配布・AI 学習・テンプレートとしての不特定多数への配布は不可 |
| きまぐれアフター背景素材置き場 https://gakaisozai.seesaa.net/ | 夕暮れの空 | 商用・加工・ツールへの収録・直リンクまで可、クレジットは自由 |

- クレジットは任意の配布元も、締めの画面に「背景: みんちりえ（URL）」のように自動で出す。
- HTML に埋め込んだ画像は取り出せる。作った動画（HTML）を渡すのは作品の一部としての利用だが、**背景を差し替えて使うテンプレートとして HTML を配らない**（OKUMONO は明文で不可）。
- 自分の画像を使うときは `bg: 画像のパス`。

## 本編の画像

`python3 <skill_dir>/fetch_images.py search "検索語"` で候補を見て、`get <番号> --as <名前>` で `images/` に取る。作者・ライセンスは `images/credits.json` に残り、
台本で `@board image: images/<名前>.jpg` と使うと、締めの画面と概要欄にクレジットが出る。

| 出どころ | 使えるもの | 決まり（2026-10-02 に確かめた） |
|---|---|---|
| Wikimedia Commons（既定） | パブリックドメイン・CC0・CC BY（`--sa` で CC BY-SA も） | API は認証なしで使える。連絡先の入った User-Agent を付け、1 つずつ取る。CC BY は作者とライセンスの表記が必須。著作権のほかの決まり（肖像・商標）は保証されない |
| Openverse（`--source openverse`） | 商用と加工を認めているもの | 匿名では 1 日 200 回ほど。元のサイトでライセンスを確かめる |

- **自動では取らない配布元**: 写真 AC・イラスト AC・ぱくたそ は、プログラムでのダウンロードを規約で禁じている。
  使うなら自分でブラウザから取り、`@board image: パス` で使い、HTML は配らず WebM にする。
- いらすとやの絵は irasutoya スキルで取れる（上の「本編の挿絵」）。商用で 1 作品 20 点まで・再配布は不可なので、`@board image: パス` で使うときも HTML は配らず WebM にする。
- CC BY-SA の画像を入れた動画は、同じ条件で共有することを求められる。分からなければ使わない。
- 人物の写真・ロゴ・商標・候補に「注意」と出た画像は使わない。図・グラフ・年表は、画像を探すより motion-video の部品で描くほうが早く、規約の心配も無い。
- 他人の写真やスクリーンショットを引用として使うときは、話の中でそれを説明し（主従）、枠で区別し、必要な分だけにし、出どころを画面に書く。雰囲気づくりの背景には使えない。

## BGM・効果音

- **集めたフリー BGM**: `bgm.json` に 18 曲（名前・雰囲気・説明・クレジット）。台本の `music:`・`@music:` に名前を書く。音声は `bgm/`（リポジトリには入れない。`fetch_assets.py` で取り直す）。
  HTML に音声を埋め込んで配る形になるので、**その形が規約で許されている配布元の曲だけ**を集めてある。

  | 出どころ | 曲 | 規約の要点（2026-10-02 に確かめた） |
  |---|---|---|
  | Kevin MacLeod（incompetech.com） | 11 曲 | CC BY 4.0。再配布・加工・商用とも可、**クレジット必須**（締めに自動で出る） |
  | PeriTune https://peritune.com/ | 2 曲 | 2026 年 2 月以前の曲は CC BY 4.0 |
  | 魔王魂 https://maou.audio/ | 4 曲 | 商用・加工は可、**著作表記が必須**。二次配布には表記と URL が要る（締めに「音楽：魔王魂 URL」が出る）。曲だけの再配布・AI 学習は不可 |
  | BGMer https://bgmer.net | 1 曲 | 商用・加工は可、表記は任意。販売・自作発言は不可。プログラムでの大量の一括ダウンロードは不可 |

- **WebM 専用の曲（OpenTracks、旧 DOVA-SYNDROME）**: 「昼下がり気分」「2:23 AM」「なんでしょう？」などの定番 13 曲と、ダウンロード数の上位 50 位からの 39 曲、計 52 曲を、`bgm.json` に `embed: false` で載せてある（音声はリポジトリに入れない）。
  39 曲の雰囲気（`mood`・`desc`）は曲名と作者の作風からの見当で、聴いて確かめていない（`desc` に「見当」と書いてある）。作者ごとの利用条件は `note`。
  OpenTracks の規約（2026-10-02 に原文を確かめた）は、動画での利用・商用・加工は可で表記も不要だが、
  「エンドユーザーが容易に音源ファイルに音声ファイルとしてアクセス、複製が可能な状態での利用」と「bot等プログラムを使用して当サイトのコンテンツ（画像・音源など）を自動的に収集する行為」を禁じている。
  - **取り方**: 自動では取らない。ブラウザで `--list-assets` に出る曲のページを開いて自分でダウンロードし、`bgm/<名前>.mp3`（`bgm.json` の `file`）という名前で置く。
  - **使い方**: 置けば `music: hirusagari` のように名前で使える。作った HTML は**手元だけで使い、配らない**。プレイヤーの「WebM で保存」で動画にして、その動画を配る。作るときに `warn:` で知らせる。
  - 曲ごとに「制作者の利用条件」が別に付くことがある。ダウンロードのページで確かめる。
- **集めていない配布元**: MusMus・甘茶の音楽工房・H/MIX GALLERY は、取り出せる形での配布が二次配布に当たるおそれがあるか、定めが無い。使うなら自分で取り、同じく WebM に書き出して使う
  （`music: bgm/曲.mp3` と `music_credit:` を書く）。
- BGM の説明（雰囲気）は曲名と一般に知られた曲調から書いたもので、全曲を聴いて確かめたものではない。使う前に 1 回聴く。
- motion-video の曲（140 曲）と効果音（221 種）は Web Audio で作る。曲のうちピアノ・弦・管楽器・和楽器などの楽器は、録音した楽器の音
  （FluidR3_GM、Frank Wen、CC BY 3.0。商用も可、クレジットが要る）で鳴らし、クレジットは締めとプレイヤーの下に自動で出る。
  合成の音だけにするなら台本の JSON の `audio.samples: false`。
- フリー BGM の配布サイトの曲を使うときは、台本の `music: bgm/曲.mp3` と `music_credit:`。
  確かめること: クレジット表記の要否と書き方・加工（ループ・音量）の可否・商用や収益化の可否・再配布（HTML に埋め込むことが再配布に当たらないか）。
- 読み上げ中は BGM が自動で下がる（台本の JSON の `audio.duck`、既定 0.35）。
