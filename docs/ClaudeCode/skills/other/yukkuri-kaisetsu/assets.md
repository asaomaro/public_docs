# 素材（立ち絵・声・BGM）と規約

このスキルは素材を同梱しない。使う人が入手した素材を読み込む。**素材ごとに利用規約があり、配布者・作品ごとに違う**。
下の内容は確かめる観点の案内で、規約そのものではない。公開・収益化の前に、必ず各配布元の最新の規約を読む。

## 立ち絵

| 置き場所 | 名前 | 中身 |
|---|---|---|
| `chars/<名前>/` | `<表情>.png` | 口を閉じた絵（`normal` は必須。無ければ仮のキャラクター） |
| | `<表情>_open.png` | 口を開いた絵（口パクに使う） |
| | `<表情>_half.png` | 半開き（任意） |
| | `<表情>_blink.png` | 目を閉じた絵（まばたきに使う。任意） |

- 背景が透明な PNG にする。高さは揃える（表示の高さは `casts.json` の `height`、既定 520px 相当）。
- PSD で配られている立ち絵は、画像編集ソフトで表情・口・目の組み合わせごとに書き出す。
- 確かめること:
  - キャラクターそのものの利用規約（例: ずんだもん・四国めたんなどは、キャラクターの利用のガイドラインがある。
    霊夢・魔理沙は原作の二次創作のガイドラインと、ゆっくり素材の配布者の規約の両方）。
  - 立ち絵の作者の規約（加工・商用・収益化・クレジットの要否）。クレジットは台本の `<名前>.credit:` に書くと締めに出る。

## 声

| 方法 | 使い方 | 確かめること |
|---|---|---|
| VOICEVOX | 起動しておき `--voicevox`（話者は `casts.json` の名前とスタイル） | 音声ライブラリ（キャラクター）ごとの利用規約。多くはクレジット表記（「VOICEVOX:ずんだもん」など）が必要で、締めに自動で出る |
| 用意した WAV | 名前順に並べて `--voices-dir`（WAV・PCM） | 作ったソフトと声の規約。ゆっくりボイス（AquesTalk 系）は、用途（収益化など）によっては有償のライセンスが必要な場合がある |
| ブラウザの読み上げ | 何も付けない | 見る人の環境の声になり、動画ファイルの録画には入らない。試しや下書き向け |

## BGM・効果音

- motion-video の曲（140 曲）と効果音（221 種）は Web Audio で合成したもので、外部の素材を使わない。
- フリー BGM の配布サイトの曲を使うときは、台本の `music: bgm/曲.mp3` と `music_credit:`。
  確かめること: クレジット表記の要否と書き方・加工（ループ・音量）の可否・商用や収益化の可否・再配布（HTML に埋め込むことが再配布に当たらないか）。
- 読み上げ中は BGM が自動で下がる（台本の JSON の `audio.duck`、既定 0.35）。

## 公開の前の確認表

- [ ] 立ち絵: キャラクターの規約と、立ち絵の作者の規約を読んだ。クレジットを入れた
- [ ] 声: 使った音声ライブラリ・ソフトの規約を読んだ。クレジット（VOICEVOX:〇〇 など）が締めに出ている
- [ ] BGM: 配布サイトと曲の規約を読んだ。クレジットを入れた
- [ ] 背景・黒板の画像・図: 自分で作ったか、使ってよいものか
- [ ] 収益化・商用: 上のすべてが収益化・商用を認めているか
