# 事実の一覧: 空はなぜ青いのか（2026-10-02 に確かめた）

## 使う事実
- [F1] 太陽の光は白く見えるが、虹のすべての色がまざっている。 — 出典: https://spaceplace.nasa.gov/blue-sky/en/ （NASA Space Place）
- [F2] 色のちがいは波の長さ（波長）のちがいで、青い光の波は赤い光の波より短い。目安は青が約 450nm、赤が約 700nm。 — 出典: https://spaceplace.nasa.gov/blue-sky/en/ 、https://en.wikipedia.org/wiki/Rayleigh_scattering
- [F3] 青い光は、空気の小さな分子にぶつかって、あらゆる方向に散らばる。波が短いので、ほかの色より強く散らばる。 — 出典: https://spaceplace.nasa.gov/blue-sky/en/
- [F4] 散らばる強さは、波長の 4 乗に反比例する（レイリー散乱）。450nm と 700nm で計算すると (700÷450) の 4 乗 ≒ 5.9 倍。 — 出典: https://ja.wikipedia.org/wiki/レイリー散乱 、https://en.wikipedia.org/wiki/Rayleigh_scattering （5.9 倍は、この法則からの計算）
- [F5] 夕方は太陽が低く、光が大気の中を長く通る。青はさらに散らばり、赤や黄がまっすぐ目に届く。 — 出典: https://spaceplace.nasa.gov/blue-sky/en/ 、https://ja.wikipedia.org/wiki/レイリー散乱
- [F6] 空が紫に見えない理由: 太陽の光に紫はもともと少ない、上空の大気で吸収される、人の目は紫に鈍い。 — 出典: https://math.ucr.edu/home/baez/physics/General/BlueSky/blue_sky.html （Usenet Physics FAQ、カリフォルニア大学リバーサイド校）
- [F7] 1859 年にティンダルが、小さな粒では青が赤より強く散らばることを見つけた。レイリー卿が 1871 年に理論にして、レイリー散乱と呼ばれる。 — 出典: https://math.ucr.edu/home/baez/physics/General/BlueSky/blue_sky.html 、https://ja.wikipedia.org/wiki/レイリー散乱
- [F8] ティンダルとレイリーは、原因を空気中のちりや水滴だと考えていた。空気の分子による散乱だと決着したのは 1911 年、アインシュタインの計算による。 — 出典: https://math.ucr.edu/home/baez/physics/General/BlueSky/blue_sky.html
- [F9] 火星は、昼の空がオレンジから赤っぽく、夕日のまわりは青灰色になる。大気が主に二酸化炭素で、細かい砂ぼこりが多いため。 — 出典: https://spaceplace.nasa.gov/blue-sky/en/

## へぇとなる点
- 夕焼けが赤いのも同じ仕組み [F5]
- 紫のほうが波が短いのに、空は紫じゃない [F6]
- 火星では逆（昼がオレンジ、夕日が青）[F9]
- 決着をつけたのはアインシュタイン [F8]

## 説が分かれる・確かめられなかった（台本に入れないか、そう言う）
- 「海の色が映っている」は誤り、と書いた出典は読めていない。台本では「よくある勘違い」とだけ言い、広まり具合は言わない。
- 5.9 倍は 450nm と 700nm を選んだときの計算。波長の取り方で変わるので「約」を付ける。
- 月や宇宙の空が黒い理由は、読んだ出典に無かったので入れない。
