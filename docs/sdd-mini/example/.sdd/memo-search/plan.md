# memo-search 実装方針

## 触るファイル
| ファイル | 何をする |
|---|---|
| src/App.jsx | 検索欄を追加し、入力を useState で保持。一覧を描く前に絞り込む |

## 方針
- 絞り込みは**表示のときだけ**行い、Dexie には問い合わせ直さない。
  メモは既に全件メモリにあるので、DB を触らない方が単純で速い。
- 大文字小文字を無視するため、比較の直前に両方 `toLowerCase()` する。

## 検討して採らなかった案
- **Dexie のクエリで絞り込む**：件数が少ないうちは DB 往復のぶん遅く、
  非同期処理が増えて素直に書けない。件数が増えて重くなってから移す。
- **専用の検索コンポーネントに切り出す**：今は入力欄1つなので分ける利がない。
  App.jsx が読みにくくなってから切り出す。

## 確認方法
| 受け入れ条件 | どう確かめるか |
|---|---|
| 「会議」で本文に含むメモだけ出る | 本文に「会議」を含むメモ1件と含まないメモ2件を作り、入力して1件だけ出るのを見る |
| 空にすると全件に戻る | 上の状態から検索欄を空にし、3件に戻るのを見る |
| 0件のとき「該当なし」 | 「zzz」と入力し、一覧が空で「該当なし」が出るのを見る |
| 「カイギ」と「かいぎ」は別物 | 本文に「かいぎ」を含むメモを足し、「カイギ」で引けないのを見る |
| 大文字小文字は区別しない | 本文に「Meeting」を含むメモを足し、「meeting」で引けるのを見る |
