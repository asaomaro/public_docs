- 削除ファイルの行に `--side RIGHT` を付けると「**反対の側にならあります**」と出る。

## 6. 未確認（正直に）

- **`--batch` の中で、同じ実行の中で作ったスレッドには返信できない**。
  書く前に全件を検証する設計の帰結で、理由は出る（テストで固定）が、
  「1 回で指摘と返信をまとめて入れたい」使い方はできない。実用上どれだけ困るかは分からない。
- 大きな `--batch`（数百件）は試していない。全件を先に検証するので、
  失敗時のメッセージが長くなりすぎる可能性がある。
- `--repo` を伴う記録 JSON 経由の検証は、**差分を取り直す**ので
  記録を書いた時点と差分が変わっていれば位置がずれる。`identity_mismatch` の警告は出るが、
  そこから先の扱いは呼ぶ側に委ねている。
- 画面から書いた記録を script で読み、さらに script から足す往復は、
  **1 往復だけ**しか試していない。
