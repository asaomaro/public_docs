# レビュー: 3 ペイン・split・ツリー・テーマ

autonomous モードのため人間のゲートは無い。**自分の差分を、他人の差分として読み直した**記録。
「動いた」ではなく「**どこで壊れるか**」を探し、見つけたものは実測で確かめてから直した。

## ラウンド 1

### must — キーボードだけで一周できていなかった（AC-I3 の不成立）

- **症状**: 差分の行にフォーカスがある状態から、**`Tab` を 60 回押してもコメント一覧に届かない**。
- **原因**: 中央ペインは行 1 つ 1 つにコメントボタンを持ち、DOM 順で右ペインはその後ろにある。
  タブ順は DOM 順なので、行の数だけボタンを通ることになる。
  `[` / `]` は「ペインを畳む」に使っており、**移動の手段が `Tab` しか無かった**。
- **見つけ方**: AC-I3 を「表を埋める」のではなく**実際に押す**検査として書いた
  （ツリー → 差分 → コメント一覧 → コメント確定、を 11 段階で追う）。書いた直後に落ちた。
- **直し**: `[` / `]` を「**そのペインへ移動**（畳んでいれば開く）」に変更。
  畳むのは `Shift` 併用（`{` / `}`）へ移した。畳む操作には他に 2 経路
  （トップバーのボタン・境界の `Enter`）があるが、移動には 1 つも無かったため。
- **確認**: `]` の **1 打鍵**でコメント一覧の項目にフォーカスが入る。`decisions.md` D8 に追記。

### must — テストが 1 件、黙って走らなくなっていた

- **症状**: テストを 1 件足したのに総数が増えなかった（59 のまま）。
- **原因**: ヘルパ関数をクラスの途中に差し込んだため、**そこから下のメソッドがクラスの外に出た**。
  `test_ui_prefs_never_reach_the_record`（AC15 の生成側の検査）が
  ただの関数になり、**実行されなくなっていた**。
- **見つけ方**: 「4 件走った」という表示が、期待の 5 件と合わないことに気づいた。
  エラーも警告も出ないので、数を見ていなければ通り過ぎていた。
- **直し**: ヘルパをクラスの外（末尾）へ移し、メソッドをクラスへ戻した。
- **確認**: `LayoutBundlingTest` が 5 件走るようになり、全体は 60 件。

### should — ペインへ移動すると、いつも絞り込みの入力へ飛んでいた

- **症状**: `]` でコメント一覧へ移ると、指摘の項目ではなく「未解決のみ」のチェックボックスに入る。
- **原因**: `querySelector('.cl-item, #cl-unresolved')` と書いていた。
  カンマ区切りは**優先順位ではなく文書順**で解決されるので、DOM で前にある絞り込みが常に勝つ。
- **直し**: セレクタを配列にして**順に試す**。
- **確認**: `.cl-item` があればそこへ、無ければ絞り込みへ。

### should — 冒頭の「差分へ移動」がフォーカスを運んでいなかった

- **症状**: skip リンクを押すとスクロールはするが、`document.activeElement` は `BODY` のまま。
- **原因**: research F7 で実測した落とし穴と同じ。一覧とコメント一覧は直したが、
  **既存の skip リンクを見落としていた**。
- **直し**: クリックを受けて、最初の行へ `tabindex="-1"` ＋ `focus()`。

### should — テーマの保存キーが 2 か所にあり、ずれても気づけない

- **症状になりうるもの**: テーマの復元は `page.html` の `<head>` に**直書き**している
  （`ui.js` より先に走る必要があるため）。`ui.js` 側の接頭辞を変えると、
  **画面は普通に動くのに設定だけ復元されなくなる**。
- **直し**: `ui.js` の `PREFIX` から組み立てた文字列が `page.html` に含まれることを検査するテスト。
- **確認**: 接頭辞を `v1` → `v2` に変える変異でテストが落ちることを確かめた。

### nit — 削除だけの行で、コメント欄の背景まで赤くなる

- **原因**: `.row[data-kind="del"]` の背景が split の行にも効いていた（色はセルごとに付けている）。
- **直し**: `.row.split { background: transparent; }`。

### nit — 使われていないコードが 1 つ

- `ui.js` の `onPref` / `listeners`（設定変更の購読）を書いたが、
  結局どこからも呼ばなかった。削除。

## ラウンド 1 で見つけたが「直さない」と決めたもの

| 事象 | 判断 |
|---|---|
| コメント一覧を描き直すとフォーカスが落ちうる | 実測で 1.7ms／150 件。落ちる経路は「指摘を解決したとき」だけで、そのとき利用者は差分側を見ている。**作り込むほどの害がない** |
| `--topbar-h` の既定 56px と実測がずれる一瞬がある | `UI.init()` が即座に測り直す。初回描画の 1 フレームだけで、目に見えない |
| ツリーのディレクトリ開閉を記憶していない | 要件（AC7・AC13）が求めるのはテーマ・幅・表示形式であってディレクトリの開閉ではない。**要件を超えて記憶を増やすと、記憶するものの線引きが曖昧になる** |

## 設計との突き合わせ

| design で決めたこと | 実装 |
|---|---|
| 生成側は触らない（D1） | `diff_review.py` の変更は `__UI_JS__` の差し込み口のみ（+7 行） |
| 現在行は 1 行に 1 つ（D2） | `.row.split` に `data-key` 1 つ。左右のコメント入れ物だけ別 |
| `light-dark()` は使わない（D3） | メディアクエリ＋`data-theme`。割り当てのずれはテストで固定 |
| 畳むのは `grid-template-columns` で（D4） | 4 パターンを宣言。回帰テストあり（`AC12b`） |
| 記憶は差分ごとではない（D5） | `diff-review-html/ui/v1/*`。digest を含めない |
| `ui.js` は状態を知らない（D7） | `localStorage` と DOM だけ。app.js との接点は `pref` / `togglePane` / `openPane` / `syncTopbarHeight` |
| 足すキーは最小（D8） | `s` / `[` / `]`（＋ Shift 併用）。**ただし割り当ての中身は実測で変えた**（上記 must） |

**設計から外れた点は 1 つ**——D8 の `[` / `]` の意味。
設計時に「畳む」と決めたのは机上の判断で、**実際に押して初めて成り立たないと分かった**。
`decisions.md` D8 にその経緯を追記した。
