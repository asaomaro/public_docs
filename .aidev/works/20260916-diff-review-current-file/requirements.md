# 要件: 現在表示中のファイルを一覧でハイライト

## 背景 / 課題

`diff-review-html` の画面は 3 ペイン（左: 変更ファイル一覧 / 中央: 差分 / 右: コメント一覧）。
中央ペインは縦に長く、複数ファイルの差分を続けてスクロールして読む。しかし**いま画面の上部に
表示されているのがどのファイルか**は、中央ペインのヘッダー行を読まないと分からず、左の一覧では
どこにも示されない。スクロールで長い差分を読み進めるほど、左の一覧との対応が分からなくなる。

## 目的 / ゴール

中央ペインをスクロールしているあいだ、**いま表示されているファイルに対応する左の一覧の項目**が
常に見た目で分かる状態にする。別のファイルの差分が画面上部に来たら、ハイライトもそのファイルへ移る。

## 完了条件（受け入れ基準）

- [ ] AC1: 中央ペインをスクロールすると、画面の上部（読んでいる位置）に表示されているファイルに
  対応する、左の一覧の項目に見た目の違い（ハイライト）がつく。
- [ ] AC2: 別のファイルが画面上部に来たら、ハイライトは古いファイルから消え、新しいファイルへ移る
  （同時に 2 件以上ハイライトされない）。
- [ ] AC3: フラット表示・ツリー表示のどちらでも同じように動く。
- [ ] AC4: ファイル一覧を検索で絞り込んでいて、いま表示中のファイルが一覧に出ていない場合は、
  ハイライトが表示されないだけで、エラーや例外にはならない。
- [ ] AC5: 参照専用（`--readonly`）の画面でも動く（読むための機能であり、書き込みの導線ではないため）。
- [ ] AC6: 読み込み直後・スクロール前の初期表示でも、いちばん上に表示されているファイルが
  最初からハイライトされている。
- [ ] AC7: 左の一覧の項目をクリックしてそのファイルへ移動したときも、ハイライトはそのクリック直後に
  移動先のファイルへ移る（次のスクロールを待たない）。
- [ ] AC8: 既存の「確認済み」表示（打ち消し線）と共存する。1 つの項目が「確認済み」かつ「いま表示中」
  の両方であってよい。
- [ ] AC9: 新しいキー操作は増やさない（既存の `[`/`]` 等はそのまま）。
