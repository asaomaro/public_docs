## 3. 実装中に**実測で見つけて直した**もの

| 症状 | 原因 | 直し方 |
|---|---|---|
| **「ファイルを開く」に `Tab` で到達できない**（20 回押しても届かない） | `<label for>` ＋ `hidden` な `<input type=file>` はどちらもフォーカスを受けない。**前 work から存在していた欠陥**（当時は「JSON を読み込む」） | 本物の `<button>` にして、`input.click()` を呼ぶ |
| ファイルを開くたびにバナーが積み上がる | `banner()` が常に append していた | 同じ種類（`key`）のバナーは**置き換える**。開く結果は 1 本に保たれる |
| `html` の出力が以前とバイト一致しない | テンプレートに「ファイルを開く」「案内」「`<script src>` の口」が増えたため（**設計時の約束が過剰だった**） | 約束を「意味の不変 ＋ 既存 60 件が通ること」に改めた（`design.md` / `tasks.md` を修正） |
| 組み立て用の印（`<!-- rw:begin -->`）が通常出力に残る | 参照専用のときしか処理していなかった | **通常でも印だけ落とす**。生成物に組み立ての痕跡を残さない |

## 追記: `--load` の撤去（deliver 後・`decisions.md` D9）

利用者から「テンプレート HTML が**どの `.dreview` を読むのか**、複数あると決まらない」という
指摘を受け、`<script src>` の焼き込み（`view --load`）を**まるごと撤去**した。

| 検査 | 結果 |
|---|---|
| 生成側 `unittest` | **83 件 OK**（`--load` 関連 3 件を、撤去を固定する 3 件に置き換え） |
| `view` / `view --readonly` / `html` / `html --readonly` の骨格に `<script src=` | **0 件** |
| `render_html` の引数に `load_src` | **無い**（復活したらテストが落ちる） |
| `view --load x.dreview` | argparse が終了コード 2 で弾く |
| 画面（32 件） | **32 / 32 pass**。口①は「ホストが注入したとき」の検査に置き換え |
| 生成物 3 種の `script[src]` と外部リクエスト | **0 個 / 本体 1 件**（実測） |

**副次的な効果**: 実行を伴う取り込み口が 1 つも無くなったので、
SKILL.md の WARNING（他人のバンドルは実行される）が不要になり、NOTE に落とせた。
`research.md` の R1 は**解消**。
